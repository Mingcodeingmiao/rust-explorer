# Community code of conduct

We welcome contributors of every background and experience level. Be respectful, assume good intent, and focus feedback on code and behavior.

Harassment, discriminatory language, threats, unwanted personal attention, disclosure of private information and sustained disruption are not acceptable. Technical disagreement is welcome; personal attacks are not.

Maintainers may edit or remove harmful content and restrict participation when necessary. Enforcement should be proportionate and consistent. To report a concern involving private information, request a private contact channel from a maintainer without posting the sensitive details publicly. Security issues follow [SECURITY.md](SECURITY.md).

This policy applies to the project's repositories, issues, pull requests and other official community spaces.
