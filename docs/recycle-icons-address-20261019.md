# 回收站、Win10 图标及地址栏修正（2026-10-19）

## 修改

- 恢复原有生成应用标识，保留原始 master，去除导出图像多余透明留白，最长边占图标画布 94%；按 DPI 使用 16/32 逻辑像素窗口图标，不再从 Explorer 加载应用图标。
- 网络改为 imageres.dll #25，此电脑 #109，已固定图钉 #5100；绕过同名 SVG/stock icon 以使用指定资源，并更新图标缓存代次。
- 关闭标签、关闭窗口、清除按钮始终使用官方 SVG。Win10 的剪切、复制、粘贴、重命名、共享、删除使用内嵌微软 Fluent SVG。资源缺失回退为 SVG，不使用 emoji。
- Win10 地址栏首图标采用系统 Segoe Fluent Icons U+E7F4；若该字体未安装，使用系统 Segoe MDL2 Assets 的相同字形，再回退至官方 SVG。
- 地址栏空白区首次点击进入输入模式并全选；再次点击完整选区时把光标放到末尾。SVG X 按截图位于输入框右侧，用于清除输入；焦点离开仍退出编辑模式。
- RE 内点击回收站改为内置 Shell namespace 列表，不启动 Windows Explorer。回收站项目保留专用 PIDL 标识、显示原始文件名；右键菜单使用真实 Shell 父项目绑定，提供还原等原生命令。菜单结束后刷新列表；短生命周期宿主使用同步调用标志。

- GUI 实测从侧边栏进入回收站，未出现新的 Explorer 窗口；自建回收站项目正确显示，原生菜单包含“还原”。
