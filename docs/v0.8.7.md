# Rust Explorer 0.8.7

本次更新重点改善右键菜单响应与设置行为，加入更新检查和校验下载，并调整视频缩略图外观。

## 新增与改进

- **检查更新**：文件夹选项 → 常规提供自动检查、手动检查、取消、下载进度和发行页面入口。仅识别本仓库较新的正式 Windows x64 发行版。
- **ZIP 下载校验**：下载 ZIP 后按发行附件 `SHA256SUMS.txt` 校验 SHA-256，成功后可打开下载目录。不提供安装器或自解压包，不会自动覆盖运行中的程序。
- **应用菜单常用命令**：完善文件夹的新标签页/新窗口打开、固定到快速访问、固定到“开始”、压缩到 ZIP/7z/TAR 和复制文件地址（Ctrl+Shift+C）。压缩能力取决于本机 Windows `tar.exe`，不针对某款第三方压缩软件编写适配。
- **视频缩略图**：大图标、超大图标的胶片条贴合实际画面，孔洞按比例缩放；竖屏和方形画面不再套两侧胶片条，应用标记不再悬在画面外。没有真实缩略图时回退普通文件图标。

## 修复

- 修复普通文件列表、此电脑和左侧驱动器导航忽略完整系统菜单开关的问题。关闭选项后使用应用菜单，仍可显式打开完整系统菜单。
- 关闭完整系统菜单时不预加载第三方扩展；保留窗口 owner 和进程内独立 STA 菜单路径，避免每次右键新建 helper。
- 未被应用接管的第三方命令在选中后交给可停止操作进程执行，避免其窗口阻塞后续菜单；文件操作继续保留结果检查与取消控制。
- 菜单、重命名和拖动过程中暂缓目录变动刷新；关闭菜单后再更新列表。抑制覆盖菜单的文件悬浮提示，并丢弃上一目录的迟到提示。
- 调整界面偏好时避免不必要的目录重新枚举；取消更新检查后，旧任务的迟到结果不再覆盖新状态。

## 下载与升级

下载 `RustExplorer-0.8.7-windows-x64.zip` 和 `SHA256SUMS.txt`，完整解压并核对校验值。退出旧版本后再替换程序。启用了默认文件夹关联时，迁移程序前先恢复系统默认，迁移后重新启用；保留恢复文件，详见[恢复说明](default-folder-browser.md)。程序目前未签名，校验值不是数字签名。

## 验证与已知边界

- Windows 本机检查通过：187 项核心测试、快捷方式测试、独立原生拖放测试及全部目标编译检查。
- 实测文件/空白处/此电脑菜单、首次与再次打开、取消及命令后的状态恢复；验证菜单开关、目录变动期间菜单保持、ZIP/7z/TAR 内容、更新检查/取消和已发布 ZIP 的校验下载。
- Windows 11 下实测明暗主题、大图标和超大图标，覆盖横屏、竖屏、方形、小尺寸及无法解码视频。
- 第三方 Shell 扩展在构建菜单时仍可能阻塞；Windows 10 原生菜单样式及所有第三方扩展尚未全面验证，不能视为所有菜单问题均已解决。
- GitHub 限流、代理和网络中断可能导致检查/下载失败，可稍后重试。下载完成后需要手动升级；没有静默安装或自动覆盖。
