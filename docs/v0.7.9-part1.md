# Rust Explorer 0.7.9 part1

发布日期：2026-10-28。基于 0.7.8，整合 [PR #40](https://github.com/Mingcodeingmiao/rust-explorer/pull/40)，面向 Windows 10/11 x64。

## 新增与改进

- **原生文件拖放**：使用 Windows OLE 数据对象与 Shell 目录目标，支持多文件数据及复制、移动、快捷方式效果协商；操作完成后刷新文件列表。多窗口和系统资源管理器通过标准 OLE 接口交互，当前人工验收边界见下文。
- **网络位置**：尝试重连断开的映射驱动器；输入 `\\服务器` 可浏览其共享列表，UNC 面包屑分开显示服务器、共享与子目录。阻塞网络调用放入有超时限制的辅助进程。
- **系统操作窗口**：点击状态栏可打开独立窗口，查看开始时间、持续时间、目标及运行结果，并停止正在进行的辅助进程操作。多个文件操作可同时记录。
- **浏览位置恢复**：恢复标签页或前进/后退历史时保留原滚动位置，选中项不再强制挤到列表顶部。
- **图像加载**：增加立即加载文件夹缩略图选项、图标/缩略图进度；按实际视图尺寸预加载图标，改进低分辨率文件图标显示和快捷方式角标。此电脑刷新时重新获取驱动器状态图标。
- **导航与菜单**：扩展面包屑下拉位置，优化箭头点击区域；启动后在进程内预热 Shell 菜单。带主窗口 owner 的右键菜单仍走独立 STA，未改回一次性 helper 路径。

## PR 检查失败原因与修复

原检查已完成核心测试和快捷方式测试，随后停在 `native_drag` 的 Shell 拖放集成测试，直到触发 GitHub Actions 的 45 分钟上限。这是交互式 Shell 测试在托管运行器中未返回，日志没有显示 Rust 编译错误；具体阻塞的系统组件无法仅凭该日志确定。

修复后，托管 CI 编译该测试并明确标记为需要交互桌面，不执行实际 Shell 传输。本地默认 `scripts/check.ps1` 会额外执行它。交互测试运行在独立子进程中，超过 60 秒即终止并报告失败，父进程清理专用测试目录，避免无限等待。

版本同步：Cargo 为 `0.7.9`；Windows 文件版本为 `0.7.9.1`，产品版本和发行标签为 `0.7.9-part1`，避免下载文件名与 EXE 版本资源不一致。

## 下载与升级

下载 `RustExplorer-0.7.9-part1-windows-x64.zip` 和 `SHA256SUMS.txt`，核对 SHA-256 后完整解压，运行 `rust-explorer.exe`。保留压缩包内的 DLL、资源和许可证文件。

升级前退出旧版本。若启用了默认文件夹关联，请先从旧版本恢复系统默认，迁移完成后再按需启用，并保留[关联恢复说明](default-folder-browser.md)。

## 已知边界

- Windows 10 原生菜单深浅色与第三方扩展兼容性仍有已知问题，未宣称完全修复。
- 原生拖放的系统数据对象、复制/移动协议和单窗口实际拖动有测试覆盖；跨可见窗口及与系统资源管理器双向拖动仍需人工验证，不能把协议测试视为全部交互验收。悬停展开、边缘自动滚动、右键跨窗口拖动尚未完善。
- 网络共享需要正确的 Windows 凭据和服务器权限；本次不覆盖全部网络设备与服务器配置。
- 停止文件操作不会撤销已完成的更改；系统弹出的外部窗口可能需要手动关闭。本次不自动执行格式化、共享权限修改或设备断开。
- 发布程序尚未进行代码签名，详细限制见[已知问题](../KNOWN_ISSUES.md)。
