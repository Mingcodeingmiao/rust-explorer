# 0.7.6 本地修复记录（未发布）

基于已合并的 PR #27，基线提交 `e1de215`。

## 快速访问列表为空

- 原因：枚举快速访问时，为判断固定状态逐项创建系统右键菜单。实机第一个条目的菜单查询超过 15 秒仍未返回；调用前检查耗时不能中断正在阻塞的 COM 调用。界面原有 1.6 秒超时会终止整个读取，启动后因此没有任何系统快速访问条目。
- 修复：列表枚举不再创建右键菜单；固定状态无法可靠获知时返回 `None`，不猜测为已固定或未固定。固定/取消固定操作仍由独立的规范动词处理流程执行。列表读取仍在可终止的辅助进程中，超时调整为 4 秒；读取失败时保留已有列表，并在快速访问页面提示 F5 重试。
- 验证：修复后两次辅助进程读取分别约 0.500 / 0.468 秒，均返回 9 个目录；GUI 左侧导航和快速访问页面均显示全部 9 项。格式检查、95 项核心测试、1 项独立快捷方式集成测试和全部 targets 编译检查通过，1 项交互删除测试跳过。
- 未改写 Windows 快速访问记录，未重新固定或删除用户目录。本轮未全面复测固定/取消固定操作；固定状态的准确展示后续应使用独立、可超时的查询，不能再次阻塞列表枚举。

本轮仅本地修复和编译，不创建发行包、不上传或发布 GitHub Release。
