# 2026-11-01 审计问题修复与验证

基于 `8fc3ec8` 修复本轮审计发现的五项问题，纳入 [0.8.1](v0.8.1.md)。下文保留版本号调整前的本地验证证据；正式发布包使用 0.8.1 版本号并重新构建。

## 修复行为

1. 系统操作在后台完成时更新进程级记录与统计缓存，不再依赖发起窗口的弱引用。任务异常退出时也会释放运行名额。
2. 撤销方向随单次请求捕获。进程级操作准入阻止撤销与复制、删除等受控修改操作交错；同一窗口还会等待已有修改回执处理完毕，避免后台结束与界面应用回执之间的空档。读取属性不必等待；对已创建项目补记历史的请求不修改文件系统，仍可正常记录。
3. SQLite 清理在立即写事务内删除所有关联表并归零统计，提交后 checkpoint，防止并发 helper 写入造成悬空图片索引。
4. 驱动器图标构造只读内存中的类型结果。首次分类排入有上限的后台队列；结果返回后通知图标更新，刷新时失效分类缓存。UNC 路径通过纯路径解析判断，不在 GUI 调用驱动器或注册表查询。
5. 操作详情在运行中约每秒刷新用时，空闲时只响应记录变化。

带 owner 的原生菜单仍走进程内独立 STA；文件操作的可取消 helper、停止与结果检查保留。
