# Rust Explorer 0.7.7 part1

发布日期：2026-10-24。基于 0.7.7 的阶段性更新，发布标签为 `v0.7.7-part1`，程序内部基础版本号保持 `0.7.7`。

> [!WARNING]
> **Windows 原生右键菜单仍有已知问题，尚未完全修复。** Windows 10 下文件菜单的深浅色或样式可能仍不一致，不同系统与 Shell 扩展组合的表现仍需排查。本次仅补强主题接口与共享子菜单处理，不能视为全部菜单问题已解决。

## 更新内容

- 文件夹选项“常规”加入语言下拉菜单，支持 English、简体中文、日本語、한국어，默认英文。应用后立即切换并保存；没有语言字段的旧配置也默认英文。系统提供的窗口和菜单项目仍使用系统语言。
- 缩略图使用 SQLite 存储，内容去重、容量限制与淘汰索引；“高级”中可设置缓存目录，重启后生效。数据库操作保留在后台。
- “双击空白返回上级”移入“细节”，默认关闭；修复鼠标不移动时快速连续双击进入多层目录失效。标签页关闭按钮稍向右移动。
- 搜索结果显示文件名、文件夹路径、修改日期、类型、大小，搜索列布局独立保存。只有确认是本地 NTFS 才使用 Everything；非 NTFS 等位置使用可取消的文件名遍历。Everything SDK 不可用时仍可能回退为当前目录名称筛选。
- 根目录的“授予访问权限”显示“高级共享…”；子目录显示“删除访问”和“特定用户…”，调用系统共享工作流。
- 补强 Windows 10 主题接口的版本判断，菜单构建后再次应用主题。保留 owner、进程内独立 STA 菜单路径与可取消文件操作之间的边界。

## 验证与限制

- 140 项核心测试、1 项快捷方式集成测试通过；1 项既有交互删除测试跳过。格式、全目标编译、发布配置构建通过。
- Windows 11 深色模式验证文件菜单首次与再次打开、根目录/子目录共享子菜单、取消，以及此电脑菜单“在新标签页中打开”后的状态恢复。
- 使用独立配置验证默认英文、四语言菜单和应用后的中文即时切换及保存；未修改系统显示语言。
- 未自动执行共享/ACL 修改、格式化或设备断开。Windows 10 菜单视觉效果和 FAT/exFAT 设备尚未完成实机验收。
- 程序未签名。请完整解压并核对 `SHA256SUMS.txt`；已启用默认文件夹关联的用户，迁移程序前先恢复系统关联，保留恢复文件。

## English

This incremental release adds manual language selection (English by default), SQLite thumbnail storage, repeated double-click navigation fixes, search result paths, and root-specific sharing commands. **Windows native context menus still have known issues, especially inconsistent styling on some Windows 10 systems. This release does not claim a complete fix.** Validation was primarily on Windows 11; see the scope above. The internal base application version remains 0.7.7.
