# Rust Explorer 0.8.12

- **磁盘容量（#61）**：「此电脑」逐盘显示查询结果。驱动器类型和容量查询受超时保护，超时会单独重试容量。旧容量最多保留 60 秒，手动刷新会重新查询。
- **默认文件夹浏览器（#62）**：支持使用带版本号的便携 EXE 启用关联，确认后会保留设置。未确认的试用仍会自动还原。
- **文件夹大小缓存**：仅在手动重新统计、满一小时或进程退出时失效。同进程多窗口同步更新，切回标签页会恢复仍有效的统计结果。

## 下载与更新

已安装旧版的用户可在「文件夹选项 → 检查更新」升级。首次安装可下载 Windows x64 便携 EXE，或完整解压 ZIP。发行附件提供 SHA-256 校验文件。
