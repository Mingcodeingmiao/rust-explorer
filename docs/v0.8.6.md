# Rust Explorer 0.8.6

本次更新将普通文件系统的右键菜单改为通用 Shell 注册菜单。

- 普通文件、文件夹和目录空白处右键，直接由 Windows Shell 根据当前选择生成菜单。已注册的压缩工具、编辑器等命令随安装环境显示。
- 移除 0.8.5 中的 Bandizip 专用探测、参数调用和菜单项。软件通过自己的 Shell 扩展决定支持的文件类型、子菜单和实际操作。
- 同步更新中英文 README、功能说明和下载入口。

## 使用与边界

下载 Windows x64 ZIP 后完整解压，再运行 `rust-explorer.exe`。可用随附的 `SHA256SUMS.txt` 核对压缩包。

当前通用路径采用传统系统菜单，尚未实现 Windows 11 新式菜单的外观。仅向 Explorer 新式菜单注册的命令是否出现，取决于相应软件提供的传统 Shell 扩展。MTP 和应用虚拟页面继续使用各自已有的菜单。

如果某个软件的命令缺失，请检查其 Shell 集成是否已启用、位数是否匹配，以及是否支持所选文件。程序通过 Shell 查询菜单，避免自行推测注册表中的命令参数。

## 验证范围

已在独立测试目录验证文件菜单、目录空白菜单和取消后的状态恢复。实测显示了本机注册的 Bandizip、编辑器、PowerRename 和目录工具命令。已有菜单 owner、进程内独立 STA 及消息转发路径继续承担原生菜单生命周期。

不同 Windows 版本和第三方扩展的兼容性仍需持续验证。
