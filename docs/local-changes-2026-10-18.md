# 本地待发布改动：2026-10-18

基于 0.6.4，按用户要求仅保留本地修改和测试包。未推送 GitHub、未创建 PR、未发布 Release。后续问题可在这批改动上继续修复，确认后一起发布。

## 本批修改

- 系统传统右键菜单返回后重新读取目录，覆盖系统菜单内删除等文件操作；原有应用删除操作完成后的刷新逻辑继续保留。
- 文件夹选项 → 查看增加高性能模式。按用户确认采用“一屏加少量缓冲”，保留有限数量的行视图，滚动时重新绑定内容和事件；不对中等、大、超大图标启用。组件池随窗口和缩放调整，数量不随大型目录的文件数无限增长。
- 内容视图独立列布局：左列含图标、名称、普通文件类型；最大 160 逻辑像素，即 175% DPI 下 280 物理像素。窄窗口缩小左列并隐藏附加列，过长名称省略。右列显示日期、大小；图片中间显示类型及原始分辨率。图片读取在后台缩略图助手中完成。
- 地址栏刷新图形缩小 20%，保留点击区域。面包屑前置电脑轮廓图标和箭头，末项后保留箭头，尾部至少留出两倍输入框高度的点击区。
- 地址栏自动补全：后台防抖、独立进程超时、过期结果丢弃；最多九行可滚动候选，带滚动条；上下键选择，回车或点击打开文件夹/文件。失焦退出输入模式。搜索框根据当前目录/全盘范围显示位置名称。
- 修复“此电脑 → 右键 → 查看 → 超大图标”崩溃。实际复现得到 GPUI DirectWrite 的 UTF-8 字节边界 panic，触发文字含人为插入的零宽字符。图标名称改为测量字形后直接绘制至多四行并省略，移除其它位置插入零宽字符的行为。
- 导航行宽度预留边距与滚动条空间，避免快速访问右侧图钉被裁切；缩小冷启动图标请求批次，降低整批查询超时的影响。

## 边界

- 路径补全单次最多枚举 20,000 项、返回 256 项，查询超时一秒；不可用或超时不阻塞输入。
- 高性能模式复用的是 GPUI 行视图，文件元数据仍由目录列表持有；不是零分配绘制。
- 本次测试使用独立临时配置及自建文件，未修改日常配置。
