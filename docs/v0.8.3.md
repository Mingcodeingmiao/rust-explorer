# Rust Explorer 0.8.3

- **网络目录标签**：切回已加载的目录标签时复用列表，恢复选中项和滚动位置。目录变更会使对应缓存失效，也可按 F5 手动刷新。
- **标签拖动**：按下标签后，鼠标移动达到 8 个逻辑像素才开始拖动。跨窗口拖入时，正确激活新移入的标签。
- **就地复制**：在原目录按 Ctrl+C、Ctrl+V 可创建文件或文件夹副本。中文 Windows 通常命名为 `报告 - 副本.txt`、`报告 - 副本 (2).txt`、`报告 - 副本 (3).txt`。

解压 Windows x64 ZIP 后运行 `rust-explorer.exe`。可使用随附的 `SHA256SUMS.txt` 核对压缩包。

发布检查覆盖核心测试和 Windows 集成检查。就地复制使用测试文件及嵌套目录验证连续编号、扩展名、内容和空目录。网络共享切换和鼠标拖动尚未进行界面实测。
