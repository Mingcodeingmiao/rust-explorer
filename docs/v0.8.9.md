# Rust Explorer 0.8.9

本版为 Windows x64 提供独立便携 EXE，并支持从程序内一键更新。相关需求见 [Issue #54](https://github.com/Mingcodeingmiao/rust-explorer/issues/54)。

## 使用与升级

- 首次使用可下载 `RustExplorer-0.8.9-windows-x64.exe`，放在可写目录后直接运行。也可以下载并完整解压 ZIP。两个文件的 SHA-256 均收录在 `SHA256SUMS.txt` 中。
- 从 0.8.8 或更早的正式版升到本版，需要先退出旧版并手动替换一次。使用默认文件夹关联时，建议保留原有 EXE 路径和名称。需要迁移路径时，请参照[恢复说明](default-folder-browser.md)。
- 从本版开始，在**文件夹选项 → 常规 → 检查更新**点击一次即可。发现较新的稳定版后，程序会下载 ZIP、验证 SHA-256、备份旧 EXE、原地替换并重启。启动时的自动检查会提示有无新版。
- 更新需要目录可写。安装前请关闭其他 Rust Explorer 窗口并等待文件操作完成。新版启动失败时会尝试恢复旧版。备份位置和手动恢复方法见[更新说明](issue54-updates-and-menu.md)。

## 其他改进

- GitHub API 限流时通过同仓库的最新发行链接检查版本。
- 第三方菜单命令重建后仍需匹配已知命令标识，避免执行另一个同名项目。
- 拖入目标窗口时直接查询项目数量，实际放下后再读取完整路径。
- 设置按修改内容合并，多个窗口或进程保存不同项目时，各自的修改都可保留。

发行程序目前未签名。SHA-256 可核对下载内容是否与发行附件一致。Windows 10、不同存储设备及第三方扩展的覆盖范围见[已知边界](../KNOWN_ISSUES.md)。

## 发布前验证

- Windows 11 本地通过 195 项核心测试、快捷方式、原生拖放及全部目标编译检查。
- 实测 GitHub 版本查询与已发布 ZIP 下载校验、目录打开、路径补全、新建、重命名、复制、撤销和视频缩略图。
- 系统删除以独立空目录验证，默认文件夹关联使用隔离注册表验证恢复流程。系统 Shell 定位测试完成后确认实际关联未更改。
- 本轮覆盖自动测试和本机冒烟测试。Windows 10、各类硬件和第三方 Shell 扩展仍需按实际环境验证。
