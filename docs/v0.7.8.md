# Rust Explorer 0.7.8

Released 2026-10-25 from PR #37.

## Highlights

- Unified SQLite-backed cache for icons, thumbnails, and document previews.
- Improved network-drive display names and volume-label validation.
- Restored saved folder views, tab scroll position, selection, and display mode.
- Toolbar sort/view/more menus are anchored to their buttons and close predictably.
- First launch detects the Windows display language (manual language selection remains available).

## Validation

- `cargo +stable-x86_64-pc-windows-gnu build --locked --release`
- `cargo +stable-x86_64-pc-windows-gnu test --locked --lib --no-default-features -- --test-threads=1`
- 141 tests passed; 1 ignored.

The Windows-native context-menu path remains owner-backed and in-process on an independent STA. Known Windows 10 native-menu styling inconsistencies are not claimed as fully resolved.
