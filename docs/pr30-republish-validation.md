### 耗时的实际边界

以下为本机诊断日志中 `menu: begin` 至 `host: showing menu` 的间隔，**不是所有机器的性能保证**，也不包含 Windows 最终绘制/输入延迟：

| 场景 | 本轮测量 |
| --- | ---: |
| 文件第一次打开 | 1336 ms |
| 同一文件再次打开 | 1242 ms |
| 目录空白菜单 | 801 ms |
| 此电脑树节点菜单 | 120 ms |

本机文件菜单包含较多第三方 Shell 扩展，主要耗时仍在 `IContextMenu::QueryContextMenu`（文件两次约 1.2–1.3 秒）。因此只能确认已去掉每次新建 helper 的回归路径，**不能宣称所有菜单已经达到 PR 作者所述的 40–80 ms**。本轮没有禁用用户扩展或修改系统设置，也没有借机改写 PR #30 的菜单逻辑。
