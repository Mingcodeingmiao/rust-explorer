## 如何处理重叠

解决了 path_completion、preview、ui、ui_extras、ui_navigation、visual 六个文件的文本冲突，并检查自动合并文件中的重复字段和接口。

- 打开行为统一为一份 Shift 设置和 Ctrl/Shift 优先级逻辑，兼容读取对方的 shift_new_tab 与本地 shift_open_tab 字段，保留 Ctrl 多选目录分别新窗口、文件交给系统打开、快捷方式解析。
- 路径候选保留后台限时 helper、请求代次取消、九行滚动与键盘选择；接入对方相对路径和环境变量展开，保留便携设备地址解析入口，避免主线程同步枚举。
- 组件复用结合对方固定可见槽位和本地 retained row Entity，保留视图回退，避免两个独立的高性能状态源。
- 内容布局统一使用 content_layout，首列上限按维护者要求为 160 逻辑像素，即 175% 下 280 物理像素；图片信息使用原图分辨率。
- 文本解码保留本地严格错误处理、编码说明和多字节截断保护，接入 GB18030 和带明显 NUL 模式的无 BOM UTF-16。编码识别存在推测性，无法可靠识别时不静默替换损坏字符。
- 保留本地磁盘组件尺寸、图标和进度条比例、选择图标、地址栏间距、标签宽度/关闭图标及一小时进程内统计缓存；原生菜单返回后保守清除统计缓存，以覆盖菜单内的文件修改。
- 接入对方便携/MTP 页面与存储信息、Shell 菜单和复制处理、回收站识别/删除保护、标签路径提示、自定义文件夹图标等新增代码。
- 修正自动合并产生的重复高性能字段、重复 Shift 选项、重复输入占位接口和搜索处理。
- 实际运行发现标签关闭按钮重复设置 hover 样式触发 GPUI 启动 panic，已去掉重复样式和重复关闭图标。
- 修正容量为零可用空间时隐藏容量条的条件，满盘仍显示容量。
- 默认文件浏览器关联按此前明确要求继续暂缓：去除其模块和设置/调用入口，没有改变系统关联。
- 源码保留对方 0.7.2 版本信息，但 README、变更记录和窗口标题明确标记为本地整合，版本号不表示已发布。
