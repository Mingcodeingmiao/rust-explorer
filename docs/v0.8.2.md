# Rust Explorer 0.8.2

本次更新集中修复便携设备（MTP）文件管理功能。

## 修复与改进

- 恢复手机内部存储根目录粘贴，以及新建文件夹、重命名入口。
- 手机内部复制和移动改为经电脑临时目录串行中转，绕过部分设备原生内部传输的忙错误。移动前检查目录结构、大小和文件哈希，验证成功后再删除源项目。
- 修复嵌套目录删除失败，逐项删除后再清理空目录；保护设备存储根目录，并为不可撤销的 MTP 删除设置撤销历史屏障。
- 协调本程序多个进程的设备访问，减少传输与图标、目录查询争用；等待过程支持停止。
- 枚举失败不再被当作完整空目录，设备繁忙时保留最近一次成功发现的设备列表。

## 验证情况

Xiaomi 14 实机通过上传、下载、内部复制和移动、中文文件名、空目录、新建、重命名、导航、刷新及测试目录清理。178 项核心回归测试通过，相关集成检查通过。详见 [实机记录](mtp-fix-validation-2026-11-01.md) 和 [审计记录](pre-release-audit-2026-11-03.md)。

## 使用与已知限制

下载并完整解压 `RustExplorer-0.8.2-windows-x64.zip`，运行 `rust-explorer.exe`，不要仅复制 EXE。可用随附 SHA256SUMS.txt 校验下载文件。

- 设备内部传输需要电脑临时目录有足够空间，暂不支持同名覆盖或目录合并。
- 移动不是原子事务；停止或源清理失败可能在两处保留副本。传输时请勿从其他程序修改源文件。
- 外部软件占用、驱动和设备差异仍可能产生忙错误。本次未覆盖拔线、设备空间耗尽、大文件压力或 MTP 拖放。
- Windows 原生菜单样式仍存在已知兼容性问题；此次保持既有进程内菜单路径。
- 二进制未签名。默认文件浏览器功能仍属实验功能，启用前请阅读恢复说明。
