# 视频缩略图边框调整（0.8.7）

旧实现把胶片条绘制在整个正方形图标槽两侧，而横屏画面只占其中一部分；胶片条最多 9 像素宽，孔距固定 8 像素，导致超大图标看起来像两根细长梯子。

改为围绕实际视频画面组合边框，孔宽、孔距随画面同比缩放。对照本机 Windows 11 资源管理器，横屏使用浅色圆角孔和深色胶片条，竖屏和方形不加胶片条。应用标记贴合实际画面，不再悬在正方形空白处。保留画面纵横比和低分辨率缩略图最小面积规则。

视频缩略图提取严格要求真实缩略图；没有解码器或提供程序失败时，显示普通文件图标，不再套上边框。视频持久缓存单独换键，照片和文件夹缓存继续使用原键。菜单分发、owner、STA 及可取消文件操作路径未改动。

## 验证

- scripts/check.ps1 通过：187 项核心测试通过、3 项按原规则忽略；快捷方式测试通过；独立系统拖放测试通过；全部目标编译检查通过。
- 新增几何测试覆盖 40/64/102/257 逻辑像素，100%/125%/175%/200% 缩放，16:9、竖屏、方形、缺少尺寸及低分辨率画面。DPI 覆盖为几何测试，并非逐个切换系统 DPI 的界面验收。
- 本机 Windows 11 界面验证：明暗主题，大图标、超大图标；四个可解码视频（横屏 MP4、竖屏 AVI、方形 AVI、小尺寸 AVI）及一个无效 MP4。边框贴合、画面比例和普通图标回退正常。
- 直接调用真实缩略图提供程序：四个有效视频均返回实际画面，无效 MP4 返回失败，不再返回伪装为缩略图的文件图标。本地结果：.tools/video-frame-probe.json。
- 优化构建完成，收录于 0.8.7。发布前界面验收使用的是相同绘制代码的本地候选版。

系统缩略图提供程序、解码器和应用关联会影响画面及标记；本次对齐实测布局，不承诺所有 Windows 版本逐像素一致。未在 Windows 10 实机测试。
