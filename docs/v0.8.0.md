# Rust Explorer 0.8.0

发布日期：2026-10-31。基于 0.7.9 part1，整合 [PR #43](https://github.com/Mingcodeingmiao/rust-explorer/pull/43)，面向 Windows 10/11 x64。

## 修复与改进

- **多窗口拖放响应**：本程序发起的窗口间文件拖放改由后台辅助进程执行复制、移动或创建快捷方式，避免目标窗口在 UI 线程内同步复制，使多个窗口一起失去响应。OLE 拖动期间定时请求源窗口重绘，结束后关闭定时器。
- **操作状态准确性**：系统操作编号改为进程级唯一，修复多个窗口编号相同导致操作已经结束、记录仍显示“正在处理”的问题。
- **操作详情窗口**：新增“清除事件”“显示主程序”和列表滚动条。“清除事件”只移除已完成记录，运行中操作继续保留停止入口；“显示主程序”会新开主窗口。
- **协作停止**：通过命名事件通知 helper，由 `IFileOperationProgressSink` 在后续回调中请求取消，覆盖没有进度窗口的文件操作；仍提供强行停止。取消不会撤销此前已经完成的更改。
- **虚拟/RAM 盘目标**：目标路径无法通过 `GetFinalPathNameByHandle` 规范化时尝试保留原路径，改善 RAM 盘根目录作为复制或移动目标的兼容性。

## 发布审查补充

为异步拖放增加本程序来源标记。只有理解“整个移动由 helper 完成”约定的本程序源，才能提前返回并后台传输。普通外部来源继续走 Shell 完成路径，避免在尚未复制内容时返回 MOVE，使外部程序提前处理源文件。该设计依据 [Microsoft Shell 数据传输约定](https://learn.microsoft.com/en-us/windows/win32/shell/clipboard)。

带主窗口 owner 的右键菜单继续在应用进程独立 STA 中执行，文件操作继续使用可取消 helper，两者生命周期没有合并。

## 验证记录

- 本机 `scripts/check.ps1` 通过：161 项核心测试通过，1 项交互删除测试按原设计忽略；快捷方式集成测试和全部目标编译检查通过。
- 交互式 OLE 测试通过：在全新临时目录验证中文文件复制/移动、内容和源文件状态；额外验证本程序来源仅入队、外部来源完成 Shell 复制后才返回。测试子进程保留 60 秒超时限制。
- 托管 CI 编译交互式测试，但不执行实际 Shell 传输。未自动执行格式化、共享权限修改或设备断开。

## 下载与升级

下载 `RustExplorer-0.8.0-windows-x64.zip` 与 `SHA256SUMS.txt`，核对 SHA-256 后完整解压，运行 `rust-explorer.exe`；保留包内 DLL、资源和许可证。Cargo 与产品版本为 `0.8.0`，Windows 文件版本为 `0.8.0.0`。

升级前退出旧版本。启用了默认文件夹关联时，请先在旧版恢复系统默认，再迁移并按需重新启用，保留[恢复说明](default-folder-browser.md)。

## 已知边界

- 与系统资源管理器等外部窗口交互时，Shell 同步 Drop 可能等待传输完成。本次不宣称所有外部程序、跨设备与冲突组合均已验收。
- 悬停自动展开、边缘自动滚动和右键跨窗口拖放尚未完善。
- 普通停止要等系统回调响应，强行停止也不会回滚已完成的操作；系统外部或提权窗口可能仍需手动关闭。
- Windows 10 原生菜单样式和第三方扩展兼容性仍有已知问题，程序目前未签名。详见[已知问题](../KNOWN_ISSUES.md)。

贡献者提供的 13,878 文件复制、删除取消结果见 [拖放记录](drag-drop.md) 与 [系统操作记录](system-operations-local-validation.md)。这些是指定环境的测量，不是所有设备或本次发布回归的性能保证。
