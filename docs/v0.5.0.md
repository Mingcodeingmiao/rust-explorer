# 0.5.0：导航、提示与交互

## 已实现

- 暗色排序、查看、三点菜单使用可见的悬停高亮。
- 主文件夹使用房屋图标，快速访问使用星形图标；导航区增加分隔线，紧凑模式减小行高。
- 系统快速访问通过 Shell namespace 后台读取，每 15 秒刷新，F5 立即刷新。与本机系统查询对照，10 个目录无缺漏。可以折叠一次，子目录不继续展开。快速访问主页有文件夹卡片和专用空白菜单。
- 固定、取消固定在本程序保存附加项和隐藏项；不会修改系统 Explorer 的固定记录。系统里新增的目录会自动出现。
- 映射网络驱动器读取容量并显示进度条；离线或超过查询时限时保留占位，不阻塞主线程。无法返回容量、零可用或只读卷不显示进度条。
- 文件类型单行截断。大图标每个项目按自己的图标和名称尺寸显示高亮；竖图使用固定容器等比缩放。选中、悬停、选中加悬停有不同颜色，取消选择保留焦点虚线。
- 约一秒悬停后显示文件信息，名称完整显示；图片含分辨率，视频含系统解析时长，EXE 含可取得的版本属性。文件夹列举少量子项并统计受限大小，未完成明确标为“至少”。
- .lnk / 本地 file URL 快捷方式可显示目标照片、视频、PDF 缩略图和左下箭头，右侧预览支持目标内容。网络、云占位、目录及不支持目标保留系统图标或说明。
- 视频缩略图增加胶片边框及关联应用小图标。仅可见项目排队，32 MiB / 512 项缓存，可取消、限时；失败回退图标。
- 设置中的“查看”页可以选择本地 DLL / EXE / MUN 或资源目录，恢复当前系统资源。仅运行时引用，不把系统素材复制进工程或软件包，不执行所选 DLL。仅识别验证过的 Shell 模块和相邻 Explorer SVG；任意文件无法自动变成完整 Win11 主题。素材使用许可仍以来源许可为准。
- 文件夹选项增加可拖动滚动条。
- 左拖保留源多选，目标文件夹高亮，鼠标旁显示操作和目标。Ctrl 复制、Shift 移动、Alt 创建快捷方式；右拖释放可选择复制、移动、创建快捷方式或取消。所有操作均先确认。默认按卷身份判断同卷移动、跨卷复制。
- [快捷键清单与兼容边界](explorer-shortcuts.md)。
- Ctrl+滚轮切换查看级别；Shift+Delete 使用独立的红色永久删除确认，明确不进入回收站。

## 可靠性与验证

原生属性、缩略图和系统枚举运行于有时限的辅助进程。目录提示统计限 160 ms / 4096 项，不跟随目录链接或主动取回云文件。UI 不同步解码媒体、递归统计目录或加载第三方 Shell 属性处理器。

使用自有夹具验证照片、视频、PDF 和快捷方式缓存；文件操作验证旧请求兼容、同卷移动、显式复制、强制跨卷移动、快捷方式和拒绝自包含目标。Windows 桌面构建通过；GUI 对照确认菜单高亮、长名称焦点框、竖图排版和拖放确认。右键拖拽通过代码及操作 helper 验证，尚未做完整自动化鼠标链路验收。

REA 对本机 explorer.exe 做完整静态资源目录检查：207 个资源，23 个图标组。此证据仅证明资源结构，不能证明任意资源 ID 的图像含义或原生行为；行为以本机 Explorer 和用户提供截图为参照。
