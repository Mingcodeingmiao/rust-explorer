# 系统操作与右键命中区域：本地修复记录

日期：2026-10-20。以下为 0.7.6 发布前的本地修复和验证记录；正式发布内容与安装说明见 [0.7.6](v0.7.6.md)。

> 2026-10-21 修订：PR #30 已将带 owner 的右键菜单恢复到应用进程独立 STA；下文“菜单也走独立进程”是原包的历史实现，已被替换。文件操作继续使用可取消 helper。当前行为与测量边界见 [PR #30 记录](pr30-republish-validation.md)。

## 修改

- 界面发起的原生菜单、属性、Shell 动词等操作移到独立辅助进程，避免 GUI 的 COM 套间或消息循环被系统扩展阻塞。初始化错误不再静默忽略。
- 状态栏增加停止入口及操作详情，显示操作名称、耗时、进行中/完成/失败/停止状态；可对单个操作强行停止。历史最多保留 32 条，同时运行最多 8 个操作。
- 普通停止尝试关闭辅助进程及其拥有的窗口；强行停止只结束本程序创建的辅助进程。已执行的文件操作不会因此回滚，共享系统宿主及提权窗口可能仍需手动关闭。
- 原生空白菜单的“新建文件夹”转交现有异步创建及就地重命名流程；格式化严格校验驱动器根路径，提供有效父窗口，处理取消与错误返回值。提权进程句柄通过 RAII 释放。
- 文件及驱动器的右键按图标、实际文本和元数据区域判断，行/卡片剩余空白使用当前目录菜单。
- 在选择命令附近加入“清空缓存”，清理内存统计、图标及缩略图缓存，以及本程序生成的磁盘 PNG/临时缓存。磁盘清理拒绝链接目录，不递归删除其他目录或文档；图标请求增加代次以隔离旧回复。
- 按修改日期排序时，无论升降序均让文件位于文件夹之前。
- 本地驱动器容量提前独立更新；导航及驱动器图标与普通文件图标分流。驱动器分别查询，避免单个慢设备拖住整批。文件夹 desktop.ini 读取移出界面线程。
- 图像缓存增加条目/字节预算；辅助进程、格式化提权句柄及菜单窗口按生命周期释放。该审查不等于证明所有系统或第三方组件不存在泄漏。

## 验证

- `scripts/check.ps1`：格式检查、103 个核心测试通过，1 个交互测试跳过；独立快捷方式集成测试通过；全目标编译检查通过。
- `cargo build --locked --release`：通过。本地独立运行目录为 `dist/RustExplorer-0.7.6-local-system-actions`，可执行文件与 release 构建的 SHA-256 一致。
- 真实窗口测试：文件名处与行内空白右键的请求分别为文件目标与目录目标；取消菜单后状态恢复。
- 系统属性窗口成功打开；普通停止关闭属性窗口，强行停止结束对应辅助进程，主窗口继续响应。详情显示耗时及停止/完成记录。
- 新建文件夹按钮在专用测试目录生成“新建文件夹 2”，刷新并进入重命名。原生“新建”子菜单自动化选择受跨进程激活影响，未声称完成该菜单项的端到端点击测试。
- 此电脑平铺、大图标、超大图标能打开，本地驱动器容量及系统图标可显示；未穷举全部视图、DPI 与第三方 Shell 扩展组合。
- 格式化测试仅打开“格式化 新加卷 (E:)”系统窗口，未点击“开始”。最初用户手动关闭后，辅助进程仍未退出。后续修复改为成功启动提权格式化窗口后立即结束启动请求并释放进程句柄，不再等待系统宿主退出或将其退出码当成格式化失败；启动/UAC 失败仍报告。此处“完成”仅表示启动请求完成，不代表磁盘已经格式化。该后续修改通过编译与自动回归，未再次执行实际格式化。
- 10 次只读原生菜单枚举辅助进程均退出。同期主进程句柄 824→836、内存约 98.8→99.3 MiB；测试期间还有界面活动，不能作为严格泄漏基准。
- 缓存清理回归测试验证只删除已知缓存位置的生成文件，保留文本及其他子目录文件。

没有执行格式化、清空用户回收站或改动默认文件管理器关联。测试仅在自建目录操作。
