# Rust Explorer 0.8.4

本次修复了「记住每个文件夹的查看方式」的设置恢复问题。[Issue #50](https://github.com/Mingcodeingmiao/rust-explorer/issues/50)

- 开启此选项后，视图、排序列、升降序和分组依据会按文件夹保存。切换标签、重新打开文件夹或重启程序时可恢复这些设置。
- 兼容旧版保存的文件夹视图，退出时会完成待写入的设置。
- 切换文件夹时清除上一目录的分组折叠状态，避免同名分组里的项目被意外隐藏。

已用两个独立测试目录验证标签切换和退出重启，并核对了内容视图、大小降序、按类型分组以及旧版的大图标设置。

下载 Windows x64 ZIP 后完整解压，再运行 `rust-explorer.exe`。可用随附的 `SHA256SUMS.txt` 核对压缩包。
