# 0.6.2 历史需求复查

日期：2026-10-17。对照本聊天全部历史需求，先审计 0.6.1 发布程序，再修复源码并构建 0.6.2。此前“全部完成”的表述证据不足：确实还缺文件撤销/重做、真正的系统背景菜单、卷标编辑、系统快速访问写回、此电脑详情列等，本次已经补实现。

以下区分“实现存在”和“实际交互通过”。没有将构建成功当成所有场景验收。后续用户要求覆盖较早冲突要求：中/大/超大名称统一最多四行并省略，选中也不展开；其余列表单行。

## 发布验证

- `cargo test --lib --no-default-features`：50 项通过。默认 GUI release 构建成功；没有声称默认特性 lib test 的工具链加载问题已解决。
- 发布 EXE 七组独立脚本全部退出 0：`verify_menu_extras_062.py`、`verify_history_062.py`、`verify_history_stdin_062.py`、`verify_quick_access_readonly.py`、`verify_font_previews.py`、`verify_shortcut_thumbnails.py`、`verify_embedded_icon.py`。另 `verify_full_shell_menus.py` 对文件、文件夹、驱动器和此电脑的只读清单检查通过。
- 1000 项历史事务请求约 261KB，通过 stdin 完成撤销/重做，绕开 Windows 命令行 32KB 限制；大 stdout/stderr 并行排空压力探针通过。历史预算 32 条/64MiB，操作中外部修改/身份替换/目标冲突拒绝。
- GUI 在独立测试副本和临时 LOCALAPPDATA 下操作自有样本；用户正在运行的版本未替换或关闭。部分截图属于同轮 0.6.1 标题的修复构建，最终发布版本号为 0.6.2。
- GUI 覆盖：无变化重命名退出、空白框选、侧栏/预览拖宽、暗色查看 hover、Details 列宽与双轴滚动、纵轮不横走、列表布局、End、最大化还原、原生驱动器菜单取消、隐藏半透明、链接箭头。
- 最终版本 `dist/RustExplorer-0.6.2-windows-x64/rust-explorer.exe` 已独立临时配置启动，GUI 重命名自有文件、Ctrl+Z、Ctrl+Y 均完成，并通过磁盘原名/新名存在性核对。最后再次撤销恢复测试文件名。自动化 Unicode `type_text` 在当前中文 IME 下未写入，改用普通按键及 IME 提交验证；不将这一自动化输入限制表述为已覆盖所有输入法。

## 不能标为全部验收的边界

没有执行真实格式化、BitLocker、USB 弹出、网络断开、卷标修改、共享权限变更。缺设备场景、全部 DPI、输入法、每个筛选组合、每级原生扩展菜单和所有拖放修饰键仍需人工覆盖。未知第三方 Shell 扩展不建立专门兼容层，符合用户保持精简的要求。

因此本次完成了查出的实质缺口并交付可测试版本，但不把历史所有需求都标成“全部交互验收通过”。详细初始证据与修复追踪见 audit-files-062.md、audit-navigation-062.md、audit-operations-062.md；其中“修复前”表格不是最终状态。
