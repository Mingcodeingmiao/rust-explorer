# Rust Explorer 0.7.6

2026-10-20 · Windows 10/11 x64 · [下载与校验文件](https://github.com/Mingcodeingmiao/rust-explorer/releases/tag/v0.7.6)

本版本整合已合并的 PR #27 与后续修复，重点改善系统右键操作、回收站、文本编辑及启动时的图标/磁盘信息加载。

## 修复

- **回收站列设置（#23）**：支持调整列宽、顺序、显示/隐藏及重置；原位置和删除日期支持排序，配置与普通目录分别保存。
- **回收站删除确认框乱码（#22）**：使用项目的 Unicode 显示名，不再把内部 PIDL 标识当成文件名。
- **深色选中颜色（#21）**：文件行选中背景调整为更明显的蓝灰色 `#36536A`。
- **启动图标与容量延迟（#28）**：本地磁盘信息先于便携设备枚举更新；导航/驱动器与普通文件图标分流，慢设备分别查询；不在界面线程读取文件夹的 desktop.ini。系统图标尚未返回时使用对应类型的后备图标。
- 修复快速访问枚举被 Shell 菜单探测拖住、列表延迟或空白的问题。
- 系统菜单与操作使用独立辅助进程及 STA 初始化，避免共享后台线程的 COM 套间冲突 `0x80010106`；初始化与操作错误不再静默忽略。
- 原生菜单“新建文件夹”转交应用的异步创建及就地重命名流程。格式化命令校验驱动器根路径并提供有效父窗口；成功启动系统格式化窗口后不再等待宿主退出或把退出码当成格式化失败。关闭/取消窗口不再触发该失败提示，启动/UAC 失败仍报告。
- 文件与驱动器右键仅在图标、文件名及实际元数据附近命中项目；行/卡片空白处打开当前目录菜单。
- 地址栏支持点击定位光标、自由选择及文本菜单；重命名时右键操作文本，无文字选区时不显示剪切/复制。重命名输入框双击选中完整文件名。
- 亮色文本选区使用 `RGB(0,120,215)`；非活跃标签和顶栏使用 `RGB(221,221,221)`，改善最大化窗口向下拖动恢复。
- 按修改日期排序时，文件在文件夹之前，升序和降序均适用。
- 包含快捷方式 `.url`/`.lnk` 图标预览、链接角标及 PR #27 的相关输入框和回收站改进；缓存版本更新，避免复用旧图像。

## 新增与优化

- 状态栏系统操作详情：操作名称、耗时、运行/完成/失败/停止状态，提供停止及单项强行停止。记录有数量上限，避免无限累积。
- 选择命令附近增加“清空缓存”，重置统计、图标及缩略图缓存；磁盘清理仅处理应用生成的已知缓存文件，不递归清理其他目录。
- 为界面图像缓存增加条目/字节预算，完善辅助进程、菜单窗口及 Win32 句柄释放。

## 使用与升级

1. 退出正在运行的旧版本，完整解压 `RustExplorer-0.7.6-windows-x64.zip` 到独立目录。
2. 对照同页 `SHA256SUMS.txt` 校验 ZIP。PowerShell 可运行 `Get-FileHash .\RustExplorer-0.7.6-windows-x64.zip -Algorithm SHA256`。
3. 运行 `rust-explorer.exe`。发布包为 Windows x64 GNU 优化构建，附运行时 DLL、可选 Everything SDK DLL、许可证和说明文档，无需浏览器运行时。程序未签名。
4. 若已启用实验性默认文件夹关联，请先通过旧版恢复系统默认，再迁移到新版并重新启用，保留备份及恢复文件。参见[恢复说明](default-folder-browser.md)。不要直接删除仍被关联的旧路径。

## 验证与边界

- 格式检查、103 个核心测试、1 个独立快捷方式集成测试、全目标编译检查及 release 构建通过；1 项交互删除测试按原规则跳过。GitHub Windows CI 的结果可在关联发布 PR 查看。
- Windows 实机检查覆盖回收站列宽/显隐、中文删除确认、选中颜色、原生菜单打开/取消、属性窗口及停止/强行停止、新建文件夹、此电脑部分视图与磁盘信息。
- 格式化只验证窗口打开，**没有执行格式化**；启动请求完成不代表磁盘已格式化。格式化操作及其确认、进度、错误由 Windows 处理。
- 停止不会回滚已经完成的文件操作；强行停止仅结束对应辅助进程，共享系统宿主或提权窗口可能仍需手动关闭。请刷新并核对结果。
- 所有 Windows 版本、DPI、设备及第三方 Shell 扩展组合未穷举。资源审查和短时重复测试不等于零泄漏保证。参见[已知边界](../KNOWN_ISSUES.md)、[系统操作验证](system-operations-local-validation.md)和[回收站验证](issues-21-23-local-validation.md)。
- 双栏、独立收藏栏、空白处双击返回上级以及文件夹背景尚未实现。MTP 同设备内复制/移动仍受设备能力限制，必要时使用电脑中转。

## English summary

0.7.6 combines merged PR #27 with fixes for Recycle Bin columns and deletion prompts (#23/#22), dark selection contrast (#21), startup drive information and icon loading (#28), Quick Access, COM apartment handling, native operations and text editing. System operations now have bounded history and stop/force-stop controls; cache clearing and bounded image caches are included. Formatting is an OS dialog launch request: closing its external host no longer produces an application failure message. No disk was formatted during validation. The unsigned Windows x64 GNU package includes runtime DLLs, optional Everything SDK, licenses and SHA-256 checksums. See the limitations above before enabling experimental folder associations or stopping file operations.
