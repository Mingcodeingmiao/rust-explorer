# 0.4.4 文件列表缩略图

中等、大、超大图标视图默认显示照片缩略图、系统能提供的视频单帧和 PDF 首页。小图标、列表、详细信息仍使用系统文件类型图标。可在“选项 → 查看 → 显示文件缩略图（中等图标及以上）”关闭。

照片通过 Windows 图片解码器缩小输出，保留比例、透明度和 EXIF 方向；视频使用 Shell 缩略图提供器，PDF 使用 Windows.Data.Pdf。缩略图最大边长为 256 像素，按当前图标尺寸、界面缩放和屏幕 DPI 选择缓存尺寸。

## 响应速度与限制

- UI 线程不读取原文件、不等待解码。普通图标先显示，后台完成后原位替换，项目尺寸不变。
- 只处理视口和少量相邻行，滚动后替换队列并取消已离开范围的任务；停稳 100 毫秒才开始新一批工作。每个窗口最多一个解码任务和一个复用的辅助进程。
- 单项 800 毫秒超时或取消后终止辅助进程，后续任务可重新启动。损坏、不支持的文件保留图标，不反复重试。切换到不使用缩略图的视图时停止解码；进程空闲 30 秒后退出。
- 调度缓存与绘制缓存分别采用最近使用淘汰；绘制缓存最多 512 项、约 32 MiB 像素预算，主动释放旧图像。不是把原图传给界面缩小。
- 磁盘缓存包含文件路径、大小、修改时间和像素尺寸；文件变化后生成新结果。缓存每五分钟检查，清理至最多 4096 张、128 MiB；检查间隔内可暂时超过该值。
- 不自动读取 UNC、网络映射盘或需要下载的云占位文件。照片、PDF 超过 128 MiB，照片超过一亿像素时保留普通图标。视频或特殊格式能否出图取决于系统提供器/编解码器。

## 验证

测试涵盖 PNG、视频帧、PDF、12MP JPEG 缩小、EXIF 旋转、文件修改缓存失效、损坏图像后继续处理、可见队列替换、取消与缓存预算。复用进程的开发构建测试中，“损坏文件 + 20 张小 PNG”约 655 毫秒完成；这是本机样例结果，不是所有图片的性能保证。

15 项单元测试通过。另在 1000 张照片的独立目录中实测了中等、大、超大图标、滚轮滚动和拖动滚动条到末尾；新视口即时显示占位图标，再补齐缩略图，没有预先解码整目录。
