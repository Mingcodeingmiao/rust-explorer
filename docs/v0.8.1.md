# Rust Explorer 0.8.1

发布日期：2026-11-01。面向 Windows 10/11 x64，基于 0.8.0 的性能与稳定性修复更新。

## 修复与改进

- **鼠标悬停反馈（Issue #44）**：修复鼠标经过文件或文件夹时，后台提示、图标及缩略图查询启动辅助进程，引起加载圆圈反复闪现的问题。只读后台进程关闭 Windows 启动反馈，保留超时、取消和通信机制。
- **关闭窗口后的操作状态**：系统操作由后台任务独立收尾。关闭发起窗口后，已结束的操作不再遗留为“正在进行”，避免积累后占满运行名额。
- **撤销与重做**：将撤销方向绑定到对应请求，避免并发复制等操作误消费另一笔撤销状态。撤销期间暂停新的受控修改操作，并等待当前窗口的历史回执应用完毕。
- **图片缓存一致性**：清空 SQLite 图标、缩略图和预览缓存时，关联记录、图片与容量统计在同一个事务内清理，避免与后台写入交错后留下无效索引。
- **驱动器图标响应**：驱动器及网络映射的分类查询移到后台有界队列，绘制时使用内存结果，减少慢设备查询阻塞界面的机会。
- **操作详情计时**：运行中操作的用时约每秒更新；没有运行中操作时，不再因计时触发重绘。

带主窗口 owner 的原生右键菜单继续保留进程内独立 STA 路径；删除、复制等文件操作继续使用可取消辅助进程及停止控制。

## 验证记录

- 本机 `scripts/check.ps1` 通过：169 项核心测试通过；快捷方式、交互式 OLE 拖放测试及全部目标编译检查通过。托管 CI 不执行交互式 Shell 传输。
- 本机 Clippy 检查与构建通过；保留已有风格及依赖未来兼容性警告。
- 在独立目录复测关闭主窗口后的属性操作收尾、实时计时、重命名撤销/重做、新建文件夹，以及文件、空白处和此电脑的系统菜单。
- 界面复制 3,000 个测试文件，在系统进度显示时按撤销，前一笔操作保持不变；复制完成后逐个比对内容无差异。
- 使用独立数据库复测缓存清理与并发写入隔离、事务回滚。详情见[审计修复记录](audit-fixes-2026-11-01.md)与 [Issue #44 验证](issue-44-hover-feedback.md)。

## 下载与升级

下载 `RustExplorer-0.8.1-windows-x64.zip` 和 `SHA256SUMS.txt`，核对 SHA-256 后完整解压，运行 `rust-explorer.exe`。请保留包内 DLL、资源及许可证。Cargo/产品版本为 `0.8.1`，Windows 文件版本为 `0.8.1.0`。

升级前退出旧版。若已启用默认文件夹关联，请先在旧版恢复系统默认，再迁移并按需重新启用，保留[恢复说明](default-folder-browser.md)。升级不会自动启用关联。

## 已知边界

- Windows 10 原生菜单样式及部分第三方 Shell 扩展兼容性仍需完善，本次不代表所有菜单问题已解决。
- 外部程序、跨设备拖放及慢网络环境仍需更多验证；悬停自动展开、边缘自动滚动和右键跨窗口拖放尚未完善。
- 停止操作不会回滚已经完成的更改；部分系统外部或提权窗口仍可能需要手动关闭。
- 程序尚未签名。测试未自动执行格式化、权限修改或设备断开；未声称覆盖所有 Windows 版本、DPI 与扩展组合。更多限制见[已知问题](../KNOWN_ISSUES.md)。
