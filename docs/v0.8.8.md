# Rust Explorer 0.8.8

本次更新集中修复系统右键菜单、拖动提示和特殊磁盘路径兼容性，并完善“此电脑”页面的菜单与分组行为。

## 菜单兼容性

- 修复完整系统菜单中第三方扩展命令（如 7-Zip“打开压缩包”）报 `0x80004001`：子菜单初始化改为尽力而为，扩展以 E_NOTIMPL 表示无需初始化时不再中止；同层同名命令按规范动词和同级序号区分。
- 左侧导航树只有真正的空白区域才显示“显示此电脑/显示网络/显示库”；右键此电脑、快速访问项目、硬盘或网络时显示项目自己的菜单。
- “此电脑”菜单移除“固定到快速访问”，避免生成无法打开的快速访问链接；修复“管理”报“系统菜单已变化”。
- 移除文件菜单中无法可靠实现的“固定到‘开始’”；完整系统菜单保留系统自己的项目。
- “此电脑”页面设备和驱动器/网络位置下方空白处改用文件夹背景菜单（查看/排序/分组/刷新/粘贴/添加网络位置/属性）；带“管理/映射网络驱动器”的项目菜单仍用于左侧树节点。

## 拖动

- 左键拖动文件到文件夹时显示与右键一致的“X 个项目 · 复制/移动到文件夹”提示；只保留一个预览图标，目标文件夹高亮，从其它应用拖入时同样高亮。
- 拖动到文件行上按“当前文件夹”处理，不再要求必须悬停在文件夹或空白处。
- 多窗口互相拖动时，预览和提示跟随指针所在窗口；源与目标位于同一文件夹时忽略请求并提示。
- 修复部分虚拟盘/网络卷拖动偶发 `os error 1`：路径规范化、文件身份读取失败时回退到绝对路径/旧版文件索引；RAM 盘上同卷判断在 `GetVolumePathNameW` 不支持时按盘符回退。

## 分组

- “分组依据”子菜单增加分隔线与“递增/递减”，仅当分组不为“（无）”时可用；分组方向按文件夹记住。
- “此电脑”页面的设备分类也按分组方向排序，类型分组保持设备和驱动器 → 便携设备 → 网络位置的规范顺序。

## 验证与边界

- Windows 本机：192 项核心测试通过、3 项忽略；`scripts/check.ps1` 通过；Release 构建成功。
- 实测 7-Zip 23.01“打开压缩包”、此电脑“管理”、左侧导航树项目菜单、单窗口/双窗口拖动、分组方向、同位置提示，以及 RAM 盘上的文件/文件夹移动与复制。
- 从其它应用拖入的完整交互、Windows 10 原生菜单样式及所有第三方 Shell 扩展仍未全面覆盖。
