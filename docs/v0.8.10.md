# Rust Explorer 0.8.10

## 更新内容

- 普通文件夹中按住 Shift 后右键点击空白处或文件，菜单新增「在此处打开 PowerShell」，并保留对应的常用操作。PowerShell 在当前目录启动。
- 修复 Rust Explorer 窗口之间涉及 MTP 设备的拖放交接。默认复制，按住 Shift 可移动。已在 Xiaomi 14 验证双向复制，设备内移动仍待确认。

## 下载和更新

- 已安装 0.8.9 的用户可在「文件夹选项」点击「检查更新」，由应用从 GitHub 下载、校验、替换并重启。
- 首次使用可直接运行 Windows x64 便携 EXE，也可完整解压 ZIP 后运行。可用同版本的 SHA256SUMS.txt 核对下载文件。
