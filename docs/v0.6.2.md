# 0.6.2 需求复查修复版

本次对照历次需求检查源码、已发布程序和自有测试文件。复查确认 0.6.1 仍有缺失，本版补齐了以下实现。

- 文件撤销/重做：复制、移动、重命名、新建、回收站恢复，记录系统实际成功目标。撤销前验证文件身份、目录内容和目标冲突；支持部分成功记录。历史最多32项/64MiB，永久删除、覆盖或目录合并设置不可撤销屏障并提示。大事务通过有界 stdin 传输，不再受 Windows 命令行长度限制。
- 完整背景菜单恢复真正的系统菜单，保留系统新建模板、共享和扩展；补应用查看、排序、分组、刷新、撤销/重做命令。
- 驱动器右键直接使用系统专用菜单；驱动器重命名独立读取、验证和修改卷标，不再把盘符根目录当普通文件名。
- 修正原生菜单隐藏 owner 无法正确取得焦点的问题，失活/取消时结束菜单；父界面在系统菜单活动期间阻止重复打开其他菜单。
- “删除访问”与“特定用户”分别对应系统完整菜单中初始化后的不同命令，不直接编辑 ACL，不再让两个入口调用相同界面。
- 快速访问支持写回系统固定/取消固定；快照不加载每项右键扩展，恢复有界快速查询。未知固定状态不丢弃项目，取消入口仍可用；系统不支持的项目有明确本地回退说明。
- 此电脑详细信息支持独立列宽拖动、保存和名称/类型/总大小/可用空间排序；网络卷补只读标志读取；卷名图标视图最多四行；紧凑模式压缩卡片。
- 修复 Ctrl+Shift+数字查看快捷键、切换视图沿用旧网格，以及 End 跳到末项却没滚到相应位置的问题。
- 四行名称补省略号；分组标题补选择、选择加悬停状态；视频角标优先使用关联播放器程序的图标；系统图标临时失败增加有界重试。

## 测试与边界

完整记录见 [audit-0.6.2.md](audit-0.6.2.md)。不能把代码检查通过等同于所有场景验收通过。

最终 0.6.2 发布程序已启动验证，GUI 重命名、Ctrl+Z 撤销和 Ctrl+Y 重做均通过，并核对了磁盘结果；50 项库测试及八组发布程序专项检查通过。ZIP 完整性和嵌入的 11 档应用图标校验通过。

本次已实测空白退出未修改重命名、框选、侧栏/预览拖宽、暗色菜单悬停、宽表格纵向滚轮、普通列宽和水平滚动条、最大化/还原后按钮、Ctrl+Shift+5 和 End 修复。独立测试文件验证了撤销重做、冲突拒绝、大请求管道、快速访问双向固定、字体和快捷方式缩略图。

用户再次授权后已恢复窗口复验：确认原生驱动器菜单可用 Esc 关闭，列表与图标模式切换立即重建布局，系统快速访问恢复显示，隐藏项半透明及目录链接箭头可见。卷标输入框等仍有待 GUI 场景覆盖，不能声称全部 GUI 验收。未执行格式化、BitLocker、USB 弹出、网络断开或共享权限变更；没有相应设备的测试不等同于已通过。

完整系统菜单会显示 Windows 实际提供的设备项目，第三方扩展由系统处理，本程序不为各第三方软件重建兼容层。导入资源仅引用所选文件及已知资源映射，不复制系统资源到软件包，不保证任意 DLL 都能提供完整的其他 Windows 版本外观。
