# MTP 与亮色标签修复、候选版回归记录

此记录在 PR #11 与本地修改整合的基础上继续验证。当前仅准备本地候选包，不推送、不创建公开 Release；发现的设备传输问题尚未解决，发布检查未通过。

后续发布决定：用户于 2026-10-18 明确要求将此版本发布到 GitHub，因此以 0.7.2 预发布版发布，并保留以下未通过项和已知问题。该决定不改变设备实测结果，也不把已知问题标记为修复。下文保留当时的候选版检查记录。

## 修复

- MTP 向上按钮原先使用 `!is_virtual` 判断，因此把手机目录与应用主页一起跳过。按钮和 Alt+↑ 现在统一调用 go_up。
- MTP 父目录使用已枚举的 Shell 祖先链；兼容 `mtp:` 与 `mtp-root:` 指向同一 PIDL 的别名。内部存储向上返回设备容量页，设备根目录向上返回此电脑。
- 无可用祖先链时，在隔离的限时 helper 中调用 Shell GetParent，不尝试按文件系统分隔符拆解 PIDL。异步结果检查请求代次，避免导航离开后旧结果覆盖当前目录。
- 亮色活跃标签改为淡蓝色 `#DEEBF7`，非活跃标签保持浅灰；暗色沿用原配色。

## 已通过

- 格式检查、76 项库测试、全部桌面目标编译通过；优化构建通过。新增测试覆盖多级父目录及设备根目录路径别名。
- 接入 Xiaomi 14 实测：此电脑 → 手机 → 内部存储 → Alarms，向上按钮回内部存储，Alt+↑ 回设备容量页，再按向上回此电脑。设备容量页正确显示总量与可用量。
- 直接 Shell parent helper 实测内部存储 → 设备根目录 → 此电脑，覆盖无缓存父目录分支。
- 亮色下两个标签对照，活跃标签淡蓝、非活跃标签浅灰。
- 手机专用新建测试目录上传至设备、下载回电脑、逐字节核对内容一致；设备文件重命名通过。
- 本地专用临时文件：复制内容一致、重命名与撤销、回收站删除与恢复、移动与撤销均实际通过。
- 整合基础版本的八种查看方式、地址补全、组件复用、Ctrl/Shift 打开及统计缓存回归记录见 `pr-11-integration-072.md`。本次改动限于导航和标签配色，不把基础记录冒充本次全部重新执行。

## 阻碍发布的问题

- 手机内部直接移动和复制测试失败：Windows IFileOperation 的 PostMoveItem 返回 `0x800700AA`（ERROR_BUSY），系统对话框显示“请求的资源正在使用中”。PerformOperations 本身可能返回成功，但 GetAnyOperationsAborted 为真，不能视为成功。
- 重连并解锁后，使用未重命名的新测试文件仍能复现，尚不能确认仅为暂时占用。没有为绕过错误自动删除源文件，也没有实现未经验证的复制后删除回退。
- 首轮测试目录在重连后已确认不存在。第二轮仅由测试创建的目录 `RustExplorer-test-3e5e5fa2ca6d48279cd8b3a8690a0e77` 清理也出现超时；用户选择稍后再清理，当前不再操作该目录。手机原有文件未执行删除、重命名或移动操作。
- 自动测试通过不能代替设备传输端到端通过；此候选版暂不满足“测试没问题后发版”的条件。
