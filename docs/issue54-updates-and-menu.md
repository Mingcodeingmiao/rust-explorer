# 更新检测与右键菜单修复（0.8.7）

## 后续补充：在程序内安装更新

在支持安装更新的版本中，打开**文件夹选项 → 常规**，点击**检查更新**即可。发现新版后，程序从 GitHub 下载、验证、安装并重启。可在安装前取消。请先关闭其他 Rust Explorer 窗口，等文件操作结束。安装目录须允许当前账号写入。启动时的自动检查会提示有无新版。

本项目沿用 GitHub Releases 的稳定版 ZIP 与 SHA-256 校验文件，由独立更新进程在退出后替换 EXE。这适合现有便携包和默认文件夹关联所需的稳定 EXE 路径。Velopack 的完整方案适合采用其打包布局和发布索引的应用，MSIX App Installer 适合签名后的 MSIX 包。参考 [Velopack 更新流程](https://docs.velopack.io/integrating/overview) 与 [MSIX 更新设置](https://learn.microsoft.com/windows/msix/app-installer/update-settings)。

GitHub API 限流时，版本检测回退到同仓库的官方最新发行链接。下载仍要求匹配当前版本标签、附件名称及其 SHA-256 校验值。

安装只替换当前 EXE，保留同目录的其他文件和用户配置。升级前会重新核对下载包的 SHA-256，并把旧版保存在程序旁的 `.rust-explorer-update-…\previous-rust-explorer.exe`。如果新版启动失败或启动后立即退出，更新助手会尝试还原并启动旧版。需要手动恢复时，退出 Rust Explorer，将备份复制到原目录并改回原 EXE 文件名。

支持该功能的 Windows 发布构建会同时产出 ZIP、可直接运行的独立 EXE 和 `SHA256SUMS.txt`。独立 EXE 可放在自选的可写目录中运行。发布时应一同上传 ZIP 和校验文件，供旧版本及程序内更新使用。0.8.8 正式版用户需要先手动换到包含安装功能的版本，之后即可在应用内安装后续更新。

以下是 0.8.7 的原始实现和实测记录。

## 更新功能

- 文件夹选项 → 常规：自动检查更新、手动检查更新、下载更新。
- 启动自动检查默认开启，每个进程只自动检查一次，可在选项中关闭。
- 仅识别本仓库较新的正式 Windows x64 版本，忽略草稿和预发布。
- 下载 ZIP 包；发行附件必须包含 `SHA256SUMS.txt`。
- 下载至 `%LOCALAPPDATA%\RustExplorer\updates` 的独立目录，先校验 SHA-256，成功后可打开下载目录。校验不是数字签名。
- 检查和下载在后台执行；网络错误、GitHub API 限流会显示失败状态，可以稍后重试。不会静默覆盖运行中的程序，也不会修改默认文件管理器关联。
- `rust-explorer.exe --check-updates` 可用于诊断。
- 检查请求限时 25 秒，区分限流、超时和网络连接失败。显示本进程上次成功检查时间，并提供发行页面入口。
- 检查/下载可取消；旧任务的迟到结果不影响后续检查。正在进行的网络读取会在返回后检查取消并清理临时下载，不强行终止进程。
- 下载时显示已接收字节数及可用时的总量/百分比。再次检查失败或取消时，保留此前已校验下载的入口。

## 菜单开关和响应

- 修正普通目录无条件进入系统菜单、绕过 `full_system_menu` 开关的问题。关闭选项后使用应用内菜单；显式“显示完整系统菜单”仍可调用 Shell 注册的扩展。
- 驱动器项目也遵循开关；回收站继续使用其专用系统命令，便携设备项目继续使用应用菜单。
- 左侧导航树的“此电脑”和驱动器同样遵循开关，导航菜单中的完整系统菜单入口可显式调用原有 STA 菜单。
- 应用菜单、设置或对话框打开时抑制文件悬浮提示，切换目录后使旧提示失效，避免提示覆盖菜单或显示上一目录的内容。
- 关闭完整系统菜单时不在启动阶段预加载第三方 Shell 扩展。
- 目录空白处在鼠标右键释放后打开菜单，与文件项目一致，避免按住右键时提前加载或等待。
- 应用菜单不再因其他后台系统操作的 busy 标记而被直接忽略。系统菜单仍避免重入。
- 文件变动通知暂缓到菜单、重命名、框选或拖动结束后刷新，避免用户正在操作时菜单突然消失或列表被替换。
- 修改菜单、语言或更新等界面偏好，不重新枚举当前目录；隐藏/受保护项目等影响列表内容的设置仍会刷新。

## 菜单修复边界

- 保留窗口 owner、进程内独立 STA 和既有菜单消息处理；没有改回每次打开菜单启动 helper。
- 防止并发开启多个进程内菜单。
- 对未被应用接管的第三方命令，菜单选中后返回已选择的菜单文字路径，在可停止的操作进程中重新解析并执行。不会跨进程复用临时命令 ID，不扫描加载无关子菜单。
- 删除、复制等原有可取消操作继续保留隔离及结果检查。
- 第三方扩展自身在构建菜单时阻塞仍可能造成等待；本次不能保证修复所有外部扩展。

## 应用菜单常用命令

- 普通文件夹菜单包含在新标签页打开、在新窗口打开、固定到快速访问和固定到“开始”。
- “固定到开始”沿用既有 Windows Shell verb；系统策略拒绝时报告错误，不提权、不修改系统权限。
- 普通文件/文件夹可使用“压缩到…”的 ZIP、7z、TAR 子菜单。压缩在后台调用本机 Windows `tar.exe`，不依赖或探测特定第三方压缩软件；旧系统不支持某格式时显示系统错误。
- 输出名称已存在时递增编号，使用独占创建预留输出文件，避免多个窗口同时压缩时覆盖彼此的文件。失败会清理本次生成的输出。
- “复制文件地址”右侧显示 Ctrl+Shift+C，列表获得焦点并有选择时快捷键可用；不会覆盖地址栏或重命名输入框的文字编辑行为。
- 打开命令使用微软 Fluent 官方图标，来源和固定提交记录在 `resources/fluent-icons/SOURCES.json`。
