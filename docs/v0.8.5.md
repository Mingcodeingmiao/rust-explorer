# Rust Explorer 0.8.5

本次更新改善文件右键菜单的布局与交互，并加入可选 Bandizip 集成。

## 更新内容

- 剪切、复制、重命名、共享和删除集中放在菜单底部。悬浮时淡入高亮，按下时显示更深的底色。
- 打开新菜单时重置上一次的悬浮状态。菜单高度和子菜单偏移适配底部操作栏。
- 后台从 Windows App Paths 查找已安装的 Bandizip。文件和文件夹可打开新建压缩包对话框，单个文件可打开选择解压目标对话框，目标文件的支持情况由 Bandizip判断。
- 隐藏文件菜单中不适用的文件夹操作，更新中英文 README 和中文、英文、日文、韩文菜单文字。

## 使用方式

下载并完整解压 Windows x64 ZIP，运行 `rust-explorer.exe`。使用随附的 `SHA256SUMS.txt` 校验下载文件。

Bandizip 需要单独安装并注册 App Paths。使用其官方命令行参数打开对话框，压缩格式和目标路径由用户确认。安装或修复 Bandizip 后，重新启动 Rust Explorer 即可重新检测。[Bandizip 参数文档](https://www.bandisoft.com/bandizip/help/parameter/)

简洁菜单由本程序绘制，尚未达到 Windows 11 原生菜单的一比一效果。任意添加软件的设置界面尚待实现。已有第三方 Shell 扩展可通过「显示完整系统菜单」访问。

## 验证范围

已在 Windows 深色模式验证底部操作栏、鼠标悬浮切换、复制并粘贴、Bandizip 压缩、解压目标对话框，以及完整系统菜单打开和点击空白取消。测试 ZIP 内容与源文件一致，源文件保留。浅色模式包含对应配色，尚未完成界面实测。

原生菜单继续通过带 owner 的进程内独立 STA 路径执行。Windows 原生菜单样式仍有已知兼容性问题。
