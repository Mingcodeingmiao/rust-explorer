# 0.4.1 逐项复查

本次直接运行了 0.4 发布程序，确认此前“代码已实现、编译通过”不能代表全部交互已经生效。以下记录区分真实界面验证、后端验证与尚未覆盖的情况。

## 已复现并修复的缺陷

| 问题 | 原因与修改 |
| --- | --- |
| 列表文件名全部变成省略号 | 嵌套 flex 容器没有给名称确定宽度；改为按单元格实际尺寸分配名称宽度 |
| 从文件名拖入文件夹没有确认框 | 文件名阻止鼠标事件冒泡，行容器无法开始拖动；名称本身也注册拖动 |
| 拖动表头时列宽意外变化 | 上一次缩放状态残留；在捕获阶段清理按下/松开状态 |
| 关闭菜单时选中了下面的文件 | 弹层缺少遮挡与事件阻断；补上 occlude 和事件处理 |
| 自绘标题栏无法移动窗口 | GPUI 0.2.2 的 Windows start_window_move 未实现，非客户区移动事件还会丢失按住状态；改为客户区捕获鼠标并使用事件坐标移动原生窗口 |
| 列表分组后后续分组无法访问 | 分组纵向堆叠但滚轮只横向移动；改为固定行数、各组向右排列，且只绘制可见列 |
| 驱动器状态图标一直不更新 | 内存和 PNG 缓存没有状态失效；驱动器图标按 30 秒周期重新查询，旧周期缓存受到限制 |
| 多个输出目录含不同旧版本 | 发布脚本同步三个原有入口，移除旧 WebView2Loader.dll，并增加可执行文件版本资源 |
| 发布说明中文损坏 | 修正文件编码，使用 UTF-8 保存 |

## 原版 Explorer 对照结果

本机系统 Explorer 的详细信息视图实测：

1. 未选中时，右键文件夹图标或文字，会选中该项目并显示项目菜单。
2. 未选中时，右键名称后面的行内空白，会显示背景菜单。
3. 先选中项目，再右键同一处行内空白，会显示项目菜单。

实现按绘制位置、实际字体测量宽度和当前选中状态区分命中区域，不把整条未选中行都视为文件名。

原版深色主题下的容量条仍使用浅灰色未用空间背景。实现改为浅灰轨道、细边框和更接近原版的厚度；卡片使用固定紧凑宽度，避免少量设备拉伸铺满整行。只读或可用空间为零时继续隐藏容量条。

## 已完成的界面验证

- 列表名称能正常单行显示；隐藏文件半透明，快捷方式左下角箭头可见。
- 从文件夹名称拖入另一文件夹会出现确认框；确认后在文件系统中核实目录已移动。
- 详细信息重命名保持行高；未修改名称时点击空白退出。
- 列宽可拖动；超宽表格出现水平滚动条；普通滚轮纵向移动不改变横向位置。
- 预览区可拖动调宽，能显示样例文本。
- 先前已验证亮色主题与选项窗口阻挡主界面。

- 标题栏拖动已确认窗口位置实际变化；连续调整列宽再拖动表头，名称列保持 476、类型列保持 112，没有残留缩放。
- 列表模式滚轮向右移动；按类型分组后仍保持固定行数，所有分组向右排列。
- 原版右键三种命中情况已对照验证；此电脑浅灰容量轨道、紧凑卡片及系统盘徽标已在界面确认。
- 130% 缩放下“查看”进入三点菜单，仍可从该入口打开查看子菜单。

发布版验证：10 项单元测试通过；同卷移动、同卷强制复制、跨卷复制、自包含目标拒绝、不同尺寸系统图标与卷属性检查通过。原生视频缩略帧为 640×360，PDF 为 512×640。Everything 客户端启动完成后 IPC 查询成功；首次后台初始化期间曾返回客户端不可用或等待超时。

窄窗口收纳的全部宽度档位、窗口边缘吸附及所有缩放比例尚未逐一实测，不能仅以编译结果标为实测通过。

## 兼容范围与未覆盖场景

- 完整系统菜单可在选项里设置为文件列表默认右键菜单；扩展兼容性取决于扩展本身。
- 八种查看模式、统计大小、列宽与列序、选项、动态磁盘树、快速访问、面包屑溢出和快捷键缩放均保留。
- 未选中名称单行省略；图标视图选中后展开，详细信息和列表保持行高并支持悬停查看全名。
- 标签转移支持同一进程内的窗口；分别启动的不同进程之间尚不支持标签转移。
- USB/ISO 实际插拔、SMB 掉线恢复、BitLocker 切换和所有第三方扩展没有完整硬件覆盖，不宣称全部验证。
- 系统图像只在运行时查询，缓存位于用户本地目录，不放入工程或发布包。
