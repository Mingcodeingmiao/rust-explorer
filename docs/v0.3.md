# 0.3 查看、导航与窗口

## 已实现

- 工具栏、标签关闭与菜单优先从当前系统 Explorer 的 FileExp 包直接加载现代 SVG；没有副本进入工程或发布包。缺失的导航、搜索、加号等使用统一线条自绘，关闭符号用中性色，悬停时才显示按钮底色。详见 `fluent-icons.md` 的 REA 证据。
- 左侧导航栏可拖动分隔线调整宽度，保存到本地设置；快速访问图钉靠右，快速访问与目录树的整行均可点击。
- 地址栏空间不足时将父级路径折叠为省略号，下拉显示各级父文件夹并可直接跳转；当前名称保持单行省略。

- 超大、大、中、小图标、列表、详细信息、平铺和内容八种查看模式。各模式继续使用虚拟列表；图标由 Windows 提供，后台加载。
- 详细信息表头边缘拖动调宽；拖动表头调整列序；右键表头选择名称、修改日期、创建日期、类型与大小列。列宽、顺序、文件夹视图和选项保存在 `%LOCALAPPDATA%\RustExplorer\settings.json`。
- 名称、日期、类型和大小排序以及分组。作者、标签、标题等需要逐文件属性处理器的字段暂不加载。
- “统计大小”只在详细信息模式执行，后台递归统计当前层每个子文件夹的逻辑字节总数，结果替换大小列。再次点击可停止，导航会取消。跳过重解析点（包括联接和挂载点），不跨挂载目录，不触发云端文件下载；跳过或不完整结果带 `*`。这是文件逻辑大小，并非 POSIX du 的已分配块大小；硬链接按路径计数。
- 文件夹选项：单双击打开、同窗或新窗浏览、记住目录视图、文件夹优先、扩展名、隐藏和系统文件、复选框、紧凑布局、长名称换行、完整路径标题和预览。只改变应用设置，不修改 Windows 全局选项。搜索页解释 Everything 和当前目录降级规则，不启用内容扫描。
- “新建”读取注册表 ShellNew 的 NullFile、Data 和本地模板，创建已安装应用的文档；不执行 ShellNew Command。支持文件夹和 Windows `.lnk` 快捷方式。
- 三点菜单按选择状态启用 ZIP、固定/收藏、复制路径、全选、取消、反选、属性、选项和窗口操作。ZIP 使用 Windows 自带 tar.exe。
- 双击打开；选中文件名后稍后单击触发行内重命名，Enter 确认、Esc 取消，文件扩展名默认不选中；F2 和系统右键重命名使用同一输入框。
- 常用操作使用轻量右键菜单，始终提供重命名、属性、复制和系统资源管理器打开；“显示完整系统菜单”保留第三方扩展。完整菜单启用 CMF_CANRENAME，重命名回到应用处理。文件夹的系统“打开”明确交给 explorer.exe；属性 helper 保持 STA 消息循环直到属性表关闭。
- 行内重命名期间点击列表空白或预览空白会结束编辑；未修改名称时直接退出，不启动文件操作。
- 自绘标题栏与标签同排，保留 Windows 移动、缩放、最小化、最大化和关闭；标签单行省略，宽度从 200 缩至 100，再通过左右按钮/横向滚动浏览。
- 标签拖动调序、拖到本程序同一进程的其他窗口，拖出标签栏创建新窗；也可在三点菜单中拆分标签。独立启动的不同进程间暂不交换标签。
- “此电脑”主页分设备/驱动器与网络位置，显示卷标、容量、剩余空间和使用条；光驱显示文件系统。网络页只展示已映射的共享，不主动扫描网络邻居或重连断开的 SMB。
- 左侧“此电脑”磁盘树按需展开。新盘符/ISO/USB/映射 SMB 通过后台枚举自动更新，容量有缓存；慢设备查询和目录树查询在有硬超时的独立进程中执行。目录树单次最多 2000 个文件夹。
- 导航栏空白处菜单支持此电脑、网络、库、所有文件夹和展开至当前目录。库当前映射文档/图片/音乐/视频已知文件夹，不解析任意 `.library-ms` 联合查询。
- 上方快速访问显示图钉，右键可在新标签/窗口打开、取消固定、复制路径、属性以及完整系统菜单；自定义固定项与取消固定均持久化。

## 边界

此版本保持普通文件系统与映射驱动器范围，不接管 explorer.exe。没有接入网络邻居发现、Shell 虚拟文件夹全套命名空间、MTP、索引内容扫描、Windows 全局文件夹选项以及作者/标签等逐文件属性扩展。这些功能不会以后台扫描方式模拟。
