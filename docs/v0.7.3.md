# Rust Explorer 0.7.3

2026-10-19 · Windows 10/11 x64

本版本整理此前本地测试改动，基于已发布的 0.7.2；本次没有合并待处理的鼠标侧键导航 PR 或 Dependabot 升级 PR。

## 新增与改进

- **实验性默认文件夹浏览器**：常规选项中主动试用，仅当前用户普通文件夹/驱动器关联；包含原值备份、120 秒未确认自动恢复、独立恢复程序和手动恢复入口。不会自动启用，不接管 Win+E、桌面 Shell 或所有写死 Explorer 的软件。[范围与恢复方法](default-folder-browser.md)。
- **外部定位**：通过内置 Shell 选择桥接打开文件夹并高亮目标文件，优先复用已有窗口。同目录的不同目标文件分别使用标签页；重复定位同一文件复用原标签页。标题随当前文件夹更新。
- **内部回收站**：在 RE 中列出项目，显示原位置、删除日期等专用列；文件及文件夹双击调用 Windows 原生属性页。清空回收站放在原文件操作栏，仍使用系统确认和进度界面。
- **常规选项**：显示版本号；启动页可选主文件夹、此电脑、快速访问；加号/Ctrl+T 可选当前目录或此电脑；快速访问文件夹可默认在新标签页打开。
- **统计大小**：一小时进程内缓存，重新进入目录自动显示有效结果；手动点击失效并重算。多选状态栏区分普通文件大小与包含文件夹结果的统计大小。
- **预览回退**：不支持的文件显示详细信息和大图标，信息区域可滚动。

## 修复

- 地址栏首次点击全选，第二次及后续普通点击定位末尾，不再跳到开头；保留键盘定位、拖选和自动补全。长路径横向滚动保持光标可见，输入背景与路径栏一致。未改动时 X 立即退出输入；清空未输入后离开地址框，恢复原路径。
- 小窗口下三级菜单覆盖前级菜单时，拦截后方鼠标事件，避免选中错误命令；菜单高度适应窗口并可滚动。
- 统一导航系统字形及指定的已知文件夹、网络、此电脑和图钉资源；Windows 10 工具栏与关闭按钮使用微软 Fluent SVG 回退，不使用 emoji。应用自身保留原有生成图标并改进有效尺寸。
- 调整标签关闭按钮居中和大小、图钉尺寸及右侧滚动条留白；亮色活跃标签与导航面板配色一致。
- 删除调用系统操作进度，完成或部分取消后刷新列表；同目录刷新保留滚动位置；新建文件夹直接创建编号名称并进入行内重命名。
- 减少无按键鼠标移动引发的实体更新；驱动器命名与固定到开始继续由系统处理，不能保证越过权限或系统策略限制。

## 验证及边界

- 96 项核心测试通过，1 项需交互的测试跳过；格式、全部桌面 targets 检查及 Windows GNU 优化构建通过。核心 IPC 测试串行运行，避免共享 Win32 消息时序导致不稳定。
- 本地 Windows 11 已验证地址栏连续点击、X 恢复、自动补全、回收站列与属性、启动页、新标签页设置、大小缓存、预览回退以及三级菜单四个显示开关。
- Windows 10 资源映射已检查，未在独立 Windows 10 主机运行。未清空用户回收站、未修改实际磁盘卷标或共享权限；默认文件夹关联的真实限时试用及恢复验证见专门文档，发布检查不会自动启用它。
- MTP 同设备复制/移动限制仍存在；串行完成任务，必要时经电脑中转。程序未签名，请完整解压并核对 `SHA256SUMS.txt`。

## English summary

0.7.3 adds opt-in recoverable folder associations, Shell file reveal, internal Recycle Bin browsing, startup/tab preferences, one-hour folder-size caching and metadata fallback for unsupported previews. It fixes address-click sequencing, restoration after clearing, overlapping submenu hitboxes, icons, refresh position and file-operation UI. Existing contributor/dependency PRs are not merged in this release. Folder associations remain experimental, disabled by default, and do not replace Win+E or the desktop Shell. MTP same-device transfer limitations remain; Windows 10 has not received an independent full GUI validation.
