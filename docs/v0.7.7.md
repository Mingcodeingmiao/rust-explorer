# Rust Explorer 0.7.7

2026-10-21 · Windows 10/11 x64 · [下载与校验文件](https://github.com/Mingcodeingmiao/rust-explorer/releases/tag/v0.7.7)

本版本从“右键菜单性能优化”开始累积：把系统菜单重新放回应用进程内，避免每次右键都新起辅助进程；修复悬浮卡片越界和其他程序抢焦点的问题；并补上快速访问与回收站地址栏的特殊处理。0.7.6 已发布的内容保持不变。

## 修复

- **系统右键菜单重新走进程内热路径**：0.7.6 的“系统操作可取消”把菜单请求也送进一次性 helper，导致每次右键都新起进程并重新加载 Shell 扩展（冷启动约 250 ms，扩展较多时接近 1 秒），0.7.5 的进程内热路径被绕过。现在只有菜单请求走进程内、带窗口 owner 的路径，其他系统操作仍保留一次性 helper 与停止/强行停止能力，右键回到 40–80 ms 的常态。
- **悬浮卡片不再越界**：文件悬浮卡片和标签页悬浮卡片改为应用窗口的附属窗口（owner = 主窗口），去掉置顶样式，只浮在本窗口之上，不会盖住其他程序；文件卡片定位在指针右下并夹紧在主窗口矩形内，应用不在前台、指针移出窗口、菜单打开或窗口失去激活时立即隐藏；标签页卡片底边与主窗口上沿齐平，窗口贴屏幕顶部时改挂到标签下方，多显示器下水平夹在窗口左右边界内。两者字号与内边距统一按“界面缩放 × 系统 DPI”计算，缩放变化时重建。
- **右键已选中的文件/文件夹**：已经选中的项目，右键它组件上的任意位置都能打开该项目自己的右键菜单；此前必须点中图标、文件名或元数据才算命中。未选中的项目仍只按图标/文件名/元数据区域命中，点它的空白处继续显示背景菜单并取消选择，不会误抢其他项目的选中状态。
- **地址栏特殊位置**：快速访问和回收站显示的名称（`快速访问`、`此电脑\回收站` 以及回收站内的子文件夹）回车后直接回到该位置，不再当成磁盘路径而无法打开；重命名“此电脑”后同样识别（不依赖缓存里的电脑名）。回收站内的文件夹在地址栏和标题中只显示自身名称，不再显示删除前的完整路径。当前目录下确实存在的同名项仍优先打开真实路径。

## 界面调整

- **文件夹选项新增“高级”页**：清空缓存、默认文件夹（实验性）、高性能模式开关和界面资源统一放在“高级”里，“常规”“查看”只保留日常设置。清空缓存从 `…` 选择菜单移除，现在只有高级页这一处入口。
- **“启动时打开”改为一行**：主文件夹、此电脑、快速访问三个按钮并排放置，不再各占一行。

## 性能与缓存

- **缩略图缓存按内容去重**：缩略图 PNG 以自身字节的 SHA-256 命名（`<sha256>.png`），同一张图只保存一份；每个项目只保存一个很小的索引（键、图片名、链接角标/照片尺寸等装饰信息）。重复内容因此不再各存一份，节省大量空间。
- 旧版按项目命名的 PNG 缓存在升级后自动清理（`thumbnails-v6`）；“清空缓存”同时清理新旧目录。共享图片上限 4096 个 / 128 MiB、索引上限 8192 个，超出按最久未用淘汰；图片被淘汰后对应项目重新生成，内容相同仍会回到同一个文件名。

## 维护约束

- 菜单请求必须保留窗口 owner 并在应用进程内显示，不能并入“一次性 helper + 可取消”路径。`src/shell.rs::execute_controlled` 顶部有醒目警告注释与 `debug_assert`，并新增回归测试 `context_menus_keep_an_owner_and_stay_out_of_the_one_shot_helper`；`CONTRIBUTING.md` 同步记录该约束，避免后续改动再次合并这两类请求。

## 使用与升级

1. 退出正在运行的旧版本，完整解压 `RustExplorer-0.7.7-windows-x64.zip` 到独立目录。
2. 对照同页 `SHA256SUMS.txt` 校验 ZIP。PowerShell 可运行 `Get-FileHash .\RustExplorer-0.7.7-windows-x64.zip -Algorithm SHA256`。
3. 运行 `rust-explorer.exe`。发布包为 Windows x64 GNU 优化构建，附运行时 DLL、可选 Everything SDK DLL、许可证和说明文档，无需浏览器运行时。程序未签名。
4. 若已启用实验性默认文件夹关联，请先通过旧版恢复系统默认，再迁移到新版并重新启用，保留备份及恢复文件。参见[恢复说明](default-folder-browser.md)。不要直接删除仍被关联的旧路径。

## 验证与边界

- 格式检查、109 个核心测试、1 个独立快捷方式集成测试、全目标编译检查通过；1 项交互删除测试按原规则跳过。GitHub Windows CI 的结果可在关联发布 PR 查看。
- 菜单耗时为本机实测（同一台机器、同一批 Shell 扩展），不同扩展组合、冷热启动和 Windows 版本会有差异；`RUST_EXPLORER_MENU_TRACE=1` 可输出 `menu: in-process …` 轨迹用于自查。
- 悬浮卡片的隐藏依赖窗口激活与前台判断；被其他程序强制抢焦点时以实际显示为准。
- 地址栏特殊名称按中英文显示名匹配（`快速访问`/`Quick Access`、`回收站`/`Recycle Bin`），其他系统语言的显示名需按实际名称输入；回收站内的条目仍只能回到回收站，不能恢复到原位置。
- 见[已知边界](../KNOWN_ISSUES.md)与[后续计划](../ROADMAP.md)。

## English summary

0.7.7 collects the work that started with the context-menu latency fix: UI Shell menus are displayed in the application process again with their window owner, so a right click no longer spawns a helper process and cold-loads Shell extensions (about 250 ms, near 1 s with many extensions) instead of the 40–80 ms in-process path. Other tracked Shell operations keep their one-shot helper and stop/force-stop controls, and a warning comment, a `debug_assert` and a regression test keep the two request classes apart. Hover cards are owned by the application window, never topmost, clamped inside it, and hidden when the window is inactive, the pointer leaves, or a menu opens; tab cards sit flush with the window top and flip below it when the window touches the screen edge. An already selected item answers a right click anywhere inside its own cell, while an unselected one still requires an icon, name or metadata hit so the empty part of a row keeps the background menu. Folder options gained an **Advanced** tab (cache clearing, experimental default-folder association, high-performance toggle, UI resource source), and the three "open at startup" buttons on the General tab now share one row. Cache clearing was removed from the `…` menu and lives only in that tab. Thumbnail PNGs are now stored under the SHA-256 of their bytes, so identical images share one file; a small per-item index keeps the key-to-image mapping and the link/photo decorations, and the previous per-item PNG cache is removed on upgrade (4096 images / 128 MiB and 8192 indexes are the caps). The address bar now resolves the displayed names of Quick Access and the Recycle Bin — including after This PC is renamed and for folders inside the bin — back to their location instead of failing as a disk path. The unsigned Windows x64 GNU package includes runtime DLLs, optional Everything SDK, licenses and SHA-256 checksums.
