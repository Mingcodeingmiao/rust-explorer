# Rust Explorer 0.7.1

发布日期：2026-10-18。此版本集中完善高性能滚动、内容视图、MTP/便携设备、地址栏与窗口布局，并修复多轮交互细节。

## 高性能模式

- 高性能列表改为固定组件池：只创建可见行加少量缓冲，滚动时复用组件，仅更新图标和文本。
- System32 等大目录不再一次性创建全部项目组件，显著降低内存和滚动卡顿。
- 分组列表不支持固定池时自动回退普通虚拟列表。
- 高性能模式遇到大图标、中图标、超大图标、内容视图时自动使用传统实现，不再禁用这些查看方式。

## 内容视图与布局

- 内容视图支持自适应第二列、名称下类型、图片分辨率、日期和大小。
- 导航栏颜色与活跃标签页一致，标签页与操作栏之间无缝隙。
- 最小化/最大化/关闭按钮贴齐窗口顶部。
- 标签文字和高度调整为原来的 90%。
- 标签页可显示完整路径：过长时缩写为 `..\目标文件夹`，再长则裁剪右侧；悬浮时在窗口上方显示完整路径原生 tooltip，不覆盖标签页。

## 地址栏与搜索

- 地址栏支持空心电脑图标、尾部箭头、点击空白进入编辑、路径自动补全和失焦退出。
- 自动补全列表按地址栏实际坐标定位，高度按候选数量动态计算，最多 9 行，不再覆盖地址栏。
- 补全项只显示图标和名称，不显示完整父路径。
- 点击地址栏右侧时光标定位到文本末尾。
- MTP 地址可显示并解析 `此电脑\设备\存储\目录`，同时接受 `mtp:` / `mtp://` PIDL 地址，回车可重新打开目录。

## MTP / 便携设备

- 此电脑枚举并显示 MTP/Android 设备；设备根页默认平铺显示存储卷，使用磁盘图标、容量进度条和“可用 / 共”文本。
- 设备根详细信息使用名称、类型、可用空间、总空间列。
- 地址栏显示完整设备/存储/目录面包屑；左侧导航树可展开 MTP 设备、存储和子目录。
- MTP 项目使用 PIDL 路径和隔离 Shell helper；支持打开、复制、剪切、删除、重命名、属性。
- MTP 右键菜单始终使用本程序菜单，即使开启“直接显示完整系统菜单”，避免不完整的系统 MTP 菜单。
- MTP 内部存储根页面禁止粘贴；普通 MTP 文件夹支持复制/粘贴，包括 MTP→MTP、MTP→本机、本机→MTP。
- MTP 删除为永久删除，不进入回收站。

## 菜单、删除与安全

- 传统文件夹菜单在“打开”下方提供“在新标签页中打开”“在新窗口中打开”；自实现菜单也提供新窗口打开。
- 完整系统菜单的文件夹空白区域提供“粘贴”，仅在文件剪贴板可用时启用。
- 删除前检测卷是否有可用回收站；U 盘、网络位置和没有回收站的可移动设备会自动走永久删除确认。
- Shift+点击删除按钮、自定义菜单 Shift+删除、Shift+Delete 均强制永久删除。
- Ctrl+双击打开全部选中文件；选中文件夹各开一个新窗口，并与 Ctrl+单击切换选择兼容。
- 文件夹选项新增 Shift+双击在新标签页打开、默认文件浏览器关联等设置。

## 图标与视觉

- 程序自加的左下角链接箭头：超大图标为原来的 200%，小图标/列表/详细信息统一为 8 px。
- 任务栏应用图标逐尺寸裁除透明边缘并重新缩放，图标在任务栏中不再明显偏小。
- 驱动器磁贴、选中/全选/反选图标、GB2312/GB18030 文本预览等细节修复。

## 性能与稳定性

- 窗口拖动时暂停后台轮询、图标/缩略图通知和文件监视刷新，减少可避免的重绘。
- 系统主题轮询节流到最多每 2 秒且只在跟随系统主题时读取注册表。
- MTP 子文件夹使用缓存文件夹图标，避免逐目录请求缓慢的 Shell 图像。
- 修复 DirectWrite 零宽空格字符边界崩溃、This PC 超大图标崩溃等问题。

## 验证

- `scripts/check.ps1`：格式检查、61 个核心库单元测试、`cargo check --locked --all-targets` 通过。
- 已实际启动验证高性能滚动、内容视图、MTP 设备枚举/浏览/复制到本机、地址栏解析、导航树展开、菜单顺序、容量页、详细信息列、自动补全、标签页路径 tooltip、链接箭头和任务栏图标。
- MTP 写入/重命名/删除未对真实手机做破坏性批量测试；相关路径已接入 `IFileOperation`，请使用测试文件验证。
- Release 构建需要 Windows SDK `fxc.exe`；若本机 SDK 不完整，请使用 GitHub Actions 的 MSVC 构建产物。
