# 0.6.4 此电脑平铺与筛选菜单

此电脑平铺卡片改为固定 250×55 逻辑像素，窗口变宽只增加列数，不再把卡片按剩余宽度拉伸。系统 DPI 为 175%、应用内缩放为 100% 时，四舍五入约为 438×96 物理像素。其他 DPI 或应用内缩放仍按比例调整。

同步减小卡片内部图标、留白和进度条，单行名称及容量信息不换行，光盘的额外类型信息仍能放入固定高度。卡片外形不再因为紧凑模式开关或窗口宽度改变。

详细信息表头筛选菜单的所有非分隔项目高度改为 26 逻辑像素，与紧凑文件行共用尺寸常量；菜单整体高度和定位计算同步更新。过长类型名称单行省略，避免把项目撑高。其他普通右键菜单保留原尺寸。

## 验证

- 53 项核心库测试、格式检查和全部编译目标检查通过；优化发布构建成功。
- GUI 实测：选中平铺驱动器后最大化窗口，卡片仍保持相同宽高，容量信息可见；详细信息筛选菜单的行距与紧凑文件行一致，选择 A–H 后正确更新结果，清除筛选可恢复。
- 175% 的 438×96 参考尺寸通过逻辑尺寸换算测试验证；本轮未修改系统 DPI 设置，也未宣称在所有物理显示器逐像素测量。
- 修正快捷方式测试中 Windows runner 的 8.3 TEMP 路径别名比较误报；没有更改快捷方式实际解析行为。
