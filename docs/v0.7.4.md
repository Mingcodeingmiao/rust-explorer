# Rust Explorer 0.7.4

2026-10-19 · Windows 10/11 x64

本版本是基于 0.7.3 的维护版本，集中修复一次针对 Shell/COM 用法的审计发现，并改善右键菜单延迟与 Windows 上的测试可用性。功能范围与 0.7.3 一致，不新增用户可见功能入口。

## 修复

- **快捷方式与 junction 缩略图**：缩略图身份校验原先跟随重解析点，与目录项本身的元数据不同源，junction / 目录符号链接因此恒判为“文件已变化”，永远拿不到缩略图。现改为同源比较（`symlink_metadata` + 目录属性位）。
- **盘根拖放自包含校验**：`canonicalize("C:\")` 返回带尾分隔符的 `\\?\C:\`，此前的字符串前缀判断会静默放过“把驱动器根拖入自身子目录”。现按路径组件比较。
- **MTP / 便携设备属性页**：原先未保持 STA、也没有消息泵，属性页可能刚创建就随 helper 退出。现全程持有 STA 并在 `ShellExecuteEx` 之后抽消息，与文件系统项走同一条路径。
- **卷信息**：`SEM_FAILCRITICALERRORS` 原先在第一个可能阻塞的查询之后才设置、且从不还原；`DRIVE_UNKNOWN` / `DRIVE_NO_ROOT_DIR` 被显示成“本地磁盘”。现改为 RAII 前置设置并还原，并显式显示“未知设备 / 未连接”。
- **已知文件夹字符串释放**：`SHGetKnownFolderPath` 的结果在字符串转换失败时不再泄漏。
- **多选右键菜单**：同父目录判断不再因路径大小写差异而误报“跨目录多选”。

## 性能

- **右键菜单**：菜单改由单个常驻 STA helper（`--shell-server`）处理，第三方 Shell 扩展保持加载。只有菜单类请求走常驻进程，其余操作仍使用一次性隔离 helper，宿主启动或通讯失败自动回落。
  实测菜单出现耗时（Windows 11 26100，本机）：修改前每次 **346–475 ms**；修改后首次 **315 ms**，之后 **61–77 ms**。
  另加 `GetCommandString` 缓存，省去每次菜单中重复两遍的逐项查询。helper 随父进程退出，不会残留孤儿进程。

## 构建与测试

- 修复 Windows 上 `cargo test` 无法启动的问题：应用清单（ComCtl32 v6）此前只链接进 bin target，测试二进制因 gpui 静态导入的 `TaskDialogIndirect` 解析失败而以 `STATUS_ENTRYPOINT_NOT_FOUND` 退出。现把资源归档同时链接到所有 target。
- 96 项核心测试通过、1 项需交互的测试跳过；GNU 优化构建通过并产出发布包。

## 验证及边界

- 本版本在 Windows 11 26100 + GNU 工具链（MSYS2 UCRT64 GCC 16.2.0）下构建与测试；未在独立 Windows 10 主机复测。
- 菜单延迟为同机实测值，随已安装的第三方 Shell 扩展数量而变化；首次菜单仍需承担一次扩展加载成本。
- 未改动“类型”列的扩展名显示、UI 图标路径上的 `desktop.ini` 同步读取，以及媒体缩略图的套间策略，均列入后续计划。
- 程序未签名，请完整解压并核对 `SHA256SUMS.txt`。

## 后续

继续文件拖动/拖放、性能与可复现 bug 修复；已记录的“类型列改用关联查询”“图标路径缓存”两项在本次未实施。见 [Roadmap](../ROADMAP.md)。

## English summary

0.7.4 is a maintenance release on top of 0.7.3 that fixes Shell/COM usage defects found in an audit: junction and directory-symlink thumbnails were always treated as changed because the identity check followed reparse points; drive-root drops were not contained because canonicalized roots carry a trailing separator; portable-device property sheets were opened without an STA or message pump; volume queries installed their critical-error guard too late and never restored it, while unknown/disconnected drives were labelled as local disks; known-folder COM strings could leak; and multi-selection menus rejected case-only parent differences. Context menus now run in one persistent STA helper that keeps Shell extensions loaded — measured menu display fell from 346–475 ms per invocation to 315 ms for the first menu and 61–77 ms afterwards — and the helper is terminated with its parent process. The embedded application manifest is now linked into every target, so `cargo test` runs on Windows again (96 passed, 1 ignored). No new user-facing features; the type column and icon-path caching remain future work.
