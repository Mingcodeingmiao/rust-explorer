# Rust Explorer 0.7.4

2026-10-19 · Windows 10/11 x64

本版本是基于 0.7.3 的维护版本，集中修复一次针对 Shell/COM 与 Win32 API 用法的审计发现，并修复 Windows 上无法运行测试的问题。功能范围与 0.7.3 一致，不新增用户可见功能入口。

## 修复（Win32 / Shell 调用）

- **快捷方式与 junction 缩略图**：缩略图身份校验原先跟随重解析点，与目录项本身的元数据不同源，junction / 目录符号链接因此恒判为"文件已变化"，永远拿不到缩略图。现改为同源比较（`symlink_metadata` + 目录属性位），并把"是否为目录"的判断从路径猜测改为属性位判断。
- **盘根拖放自包含校验**：`canonicalize("C:\")` 返回带尾分隔符的 `\\?\C:\`，此前的字符串前缀判断会静默放过"把驱动器根拖入自身子目录"。现按路径组件比较，而不是比较字符串。
- **MTP / 便携设备属性页**：原先未保持 STA、也没有消息泵，属性页可能刚创建就随 helper 退出。现全程持有 STA 并在 `ShellExecuteEx` 之后抽消息，与文件系统项走同一条路径。
- **卷信息**：`SEM_FAILCRITICALERRORS` 原先在第一个可能阻塞的查询之后才设置、且从不还原；`DRIVE_UNKNOWN` / `DRIVE_NO_ROOT_DIR` 被显示成"本地磁盘"。现改为 RAII 前置设置并还原，并显式显示"未知设备 / 未连接"。
- **已知文件夹字符串释放**：`SHGetKnownFolderPath` 的结果在字符串转换失败时不再泄漏。
- **多选右键菜单**：同父目录判断不再因路径大小写差异而误报"跨目录多选"。
- **路径补全与图标读取**：`entry.metadata()` 统一改为 `symlink_metadata` 同源读取；图标/属性读取统一走 COM 初始化与消息泵，避免在无套间线程上调用 Shell。

## 构建与测试

- 修复 Windows 上 `cargo test` 无法启动的问题：应用清单（ComCtl32 v6）此前只链接进 bin target，测试二进制因 gpui 静态导入的 `TaskDialogIndirect` 解析失败而以 `STATUS_ENTRYPOINT_NOT_FOUND` 退出。现把资源归档同时链接到所有 target（不要同时追加 `rustc-link-arg`，否则会出现 `.rsrc merge failure: multiple non-default manifests`）。
- 96 项核心测试通过、1 项需交互的测试跳过；GNU 优化构建通过并产出发布包。

## 验证及边界

- 本版本在 Windows 11 26100 + GNU 工具链（MSYS2 UCRT64 GCC 16.2.0）下构建与测试；未在独立 Windows 10 主机复测。
- 未改动“类型”列的扩展名显示、UI 图标路径上的 `desktop.ini` 同步读取，以及媒体缩略图的套间策略，均列入后续计划。
- 程序未签名，请完整解压并核对 `SHA256SUMS.txt`。

## English summary

0.7.4 is a maintenance release on top of 0.7.3 that fixes Shell/COM and Win32 usage defects found in an audit: junction and directory-symlink thumbnails were always treated as changed because the identity check followed reparse points; drive-root drops were not contained because canonicalized roots carry a trailing separator and the check compared strings; portable-device property sheets were opened without an STA or message pump; volume queries installed their critical-error guard too late and never restored it, while unknown/disconnected drives were labelled as local disks; known-folder COM strings could leak; and multi-selection menus rejected case-only parent differences. The embedded application manifest is now linked into every target, so `cargo test` runs on Windows again (96 passed, 1 ignored). No new user-facing features; the type column and icon-path caching remain future work.
