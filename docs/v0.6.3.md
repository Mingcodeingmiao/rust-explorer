# 0.6.3 布局修复

- 文件夹选项的搜索说明启用换行，内容区允许收缩；说明、设置标签和按钮组保持在弹窗边界内。弹窗适配可用窗口大小，长内容继续使用纵向滚动。
- 修复超大文件夹图标忽大忽小：Windows Shell 对 256px 请求可能返回已有的 48px 缓存。文件夹合成缩略图按统一图标槽显示，并请求 Shell 放大/选用更大缓存；普通图片仍保留小图居中加框规则。文件夹快捷方式也携带目标目录类型。新缩略图缓存版本避免沿用旧结果。
- 地址栏仅将放不下的最左侧祖先逐个收进“…”菜单，尽量保留靠近当前位置的路径段；弹出菜单只列出隐藏项目，并可跳转。当前目录本身过长时仍会省略文字。

## 回归依据

修复前实测，同一台机器在请求 C:\Windows、C:\Program Files 的 256px 文件夹缩略图时返回 48×48；C:\Users 则返回 256×256。旧显示规则把两者分别按最小边长和全尺寸展示，造成明显大小差异。

新增几何回归测试覆盖低/高分辨率文件夹在不同缩放下统一大小、普通图片保持原规则，以及地址栏仅隐藏最小前缀、极窄空间仍保留当前目录。

验证：52 项核心库测试、格式和全部编译目标检查通过；优化发布构建成功。只读 helper 在先请求 48px 再请求 256px 的热缓存场景中，对 Windows、Users、Program Files 三个文件夹均返回 256×256；重复 256px 请求通过。快捷方式图片/视频/PDF 回归及 11 档 EXE 图标校验通过。

GUI 使用独立副本和临时配置实测：搜索说明完整换成两行且未越过弹窗，查看页可纵向滚动到底部；长路径保留多个末尾目录，三点菜单只包含隐藏的三个祖先，点击其中一项正确跳转。其余历史场景不作为本次全量重验。

超大图标页面等待后台加载后，多种内容的文件夹合成预览保持一致尺寸，不再出现某个文件夹缩成中央小图的现象。
