# 文件夹大小缓存

统计结果保存在当前进程内存中，完成统计后有效期为一小时，退出程序后清空。多个窗口共享缓存，最多保留 4096 项。

打开目录或切回标签页时，自动读取当前文件夹列表中已有的有效缓存，并显示统计大小；没有缓存的目录不会自动触发递归扫描。缓存读取不会延长有效期。

手动点击“统计大小”会清除当前列表中目录的旧缓存，并重新扫描。其他目录的有效缓存保留。统计过程中再次点击仍为停止统计；停止后再次点击可重新计算。取消的任务不写入缓存，旧任务的界面消息也不会覆盖新的统计结果。

缓存期间外部程序修改的内容可能不立即反映在大小中，可手动重新统计。RE 内显式文件操作继续使用原有缓存失效机制。

- 测试覆盖一小时有效期边界、取消任务、缓存读取、指定目录失效及其他目录缓存保留。
