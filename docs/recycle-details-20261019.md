# 回收站详情与地址栏后续修正（2026-10-19）

- 常规选项新增当前软件版本行，从 Cargo 构建版本自动读取，目前为 0.7.2。
- 回收站默认进入详细信息视图，显示名称、原位置、删除日期、大小、项目类型、修改日期；原位置和删除日期读取系统 Shell 属性，文件夹大小使用回收站保存的大小，不重新扫描。
- 回收站文件和文件夹双击均调用 Windows 原生属性页，不进入目录或打开关联程序。预览提示同步改为“双击查看系统属性”。属性页包含原位置、大小、删除时间和还原按钮，并保持系统属性宿主存活。
- 工具栏下增加“清空回收站”，调用 SHEmptyRecycleBinW，保留系统确认、进度和错误提示。结束后重新读取列表。未在用户回收站执行真实清空测试。
- 图钉仍使用 imageres.dll #5100，裁掉多余透明留白，按 18 逻辑像素显示，并更新缓存代次。
- 刷新字形从 12.8 增至 16 逻辑像素，即上版的 125%；按钮高恢复为 32，和其他导航按钮垂直居中。
- 地址首次点击全选，后续普通点击保持末尾光标，键盘和 Shift 选区仍可编辑。X 清除后若没有输入内容，离开输入框会恢复当前路径。
