# 0.6.0 人工测试版

本版按用户要求冻结功能供人工测试，尚不代表所有交互已完成逐项 GUI 验收。

## 本版变更

- 空白区域按住左键拖动框选，Ctrl/Shift 配合选择。
- 新建下拉箭头及工具栏分隔线。
- 自有 Win32 传统菜单，背景有查看、排序、分组、刷新；按界面主题尝试深色菜单，不加载第三方 Shell 扩展。
- 授予访问权限入口：特定用户打开 Windows 官方共享向导；删除访问入口打开系统共享设置，由用户自行确认权限变更。后者尚未复刻截图中的“停止共享”专用向导。
- TTF/OTF/TTC 字体样张与缩略图，在隔离进程中临时加载，不安装字体；TTC 使用第一个字体，FON 依赖系统提供程序。
- 详细信息表头下拉筛选：名称、拼音、日期、类型、大小；支持多列组合。拼音使用首字默认读音，不做多音词消歧。
- 分组标题单击选组，双击折叠或展开；列表分组不折叠。
- 此电脑八种查看方式；默认平铺、按类型分组，详细信息有总大小与可用空间，列表和详细信息有横向滚动条。
- 中、大、超大图标放大约 1.6 倍。小图标不变。小缩略图居中加框，保留合适的原始分辨率，超大图才缩小。
- 文件夹优先请求 Windows 内容缩略图；失败立即回退普通图标，不递归扫描子项。网络、脱机和云占位内容不自动生成缩略图。
- 修复竖图比例、文件夹缩略图透明通道，增加旧低分辨率图标的居中边框。
- 提高窗口小图标及大图标加载分辨率，供任务栏与窗口切换使用。
- 筛选后键盘选择、Shift 范围、全选和文件操作保持正确的可见索引。

## 测试边界

已运行库测试、真实字体与快捷方式辅助进程测试、桌面编译检查。部分 GUI 验收被本机输入打断，框选、传统菜单深色、分组、所有此电脑视图和滚动条仍请重点人工测试。共享及访问权限未做任何自动修改。

此前仍未实现的项目：完整文件操作撤销/重做、导航树的全量键盘导航。第三方 Shell 菜单和虚拟网盘扩展按本轮要求不再兼容。Windows 的缩略图和暗色菜单效果受系统版本、提供程序及资源影响；失败有回退。

源码和可执行文件均标识 0.6.0。系统图标仅运行时引用，不包含在软件包；原软件图标为项目自己的图标。拼音字典许可见软件包 pinyin-LICENSE.txt。
