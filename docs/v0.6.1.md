# 0.6.1 人工测试版

- “显示完整菜单”恢复 Windows Shell 的实际 IContextMenu，保留系统提供的项目和子菜单，并继续应用暗色菜单设置。普通文件、文件夹、驱动器、此电脑分别取得对应的原生菜单。BitLocker、弹出、断开连接等项目是否出现由设备和系统状态决定。
- 此电脑默认名称排序改为盘符顺序，容量等其他排序仍可使用。
- junction、目录符号链接显示快捷方式箭头；云占位 reparse 不误标。目录快捷方式在隔离进程解析后交给本程序导航，循环和过深链接报错。
- 字体双击明确调用 Windows Font Viewer，不安装字体。
- 中、大、超大图标名称始终最多四行，超出省略，选中不改变此规则。重命名框按文字长度伸缩，长名称软换行，详细信息行高度保持不变；输入法组合输入同步更新尺寸。
- 导航树增加 F6 焦点、方向键、Home/End、Enter/Space、展开和收起、菜单键及 Shift+F10。星号只展开受限数量的直接子项，避免递归扫描。

验证包括 38 项库测试、真实快捷方式与 junction、原生菜单只读清单、桌面版构建和发布包检查。未执行格式化、BitLocker、共享权限变更、弹出或网络断开等设备操作；本机没有可用于验证的 USB/映射网络驱动器。GUI 自动检查受到窗口激活限制，文件名编辑和菜单外观请重点人工验收。

此前清单仍有边界：完整文件操作撤销/重做尚未实现；自绘“删除访问”入口仍是系统共享设置页。系统完整菜单中的共享项目现在由系统自身提供。本版不声明历史所有交互均已完成验收。
