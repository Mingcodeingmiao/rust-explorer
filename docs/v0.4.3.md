# 0.4.3 窗口拖动与还原修复

先前为了恢复窗口拖动而直接调用 SetWindowPos，这绕过了 Windows 原生拖动循环，无法触发屏幕边缘贴靠。现移除手工移动逻辑，恢复 HTCAPTION 原生拖动。GPUI 根容器的自动聚焦会 prevent_default，阻止非客户区默认操作，因此将焦点跟踪移到标题栏下方的内容区域。

右上角最小化、最大化/还原、关闭按钮改为独立固定区域，始终锚定标题栏右侧；标签和可拖动空白区为它预留空间。按钮使用原生非客户区行为，移除重复的手工窗口命令。

验证：独立测试程序中确认原生标题栏拖动可用，双击最大化再双击还原后，三个按钮正常显示。用户已确认屏幕边缘贴靠可用，之后未再执行边缘贴靠测试。保留 0.4.2 原创多尺寸应用图标。
