# Rust Explorer 0.7.2

发布日期：2026-10-18。此版本是 0.7.1 的修复版，重点修复传统系统菜单复制、文件行右键菜单、粘贴位置和文件夹自定义图标。

## 修复

### 传统菜单复制

- 传统 Shell 文件菜单的「复制/剪切」不再依赖短生命周期 helper 的异步 Shell 剪贴板，而是直接写入 Windows `CF_HDROP` 剪贴板。
- 复制后 helper 退出仍可正常粘贴；已用测试文件验证剪贴板内容和目标文件夹粘贴。
- 当系统剪贴板序列号变化时，会清除内部 MTP 剪贴板，避免传统菜单复制后被旧 MTP 项目覆盖。

### 文件行右键菜单

- 右键文件行的任意位置（包括类型、大小等列）都会选中该文件并打开文件菜单。
- 修复旧逻辑在文件名区域外右键时清空选择并打开文件夹空白菜单的问题。

### 粘贴位置

- 完整系统菜单的「粘贴」移动到「刷新」下方；当前顺序为查看、排序、分组、刷新、粘贴、撤销、重做。

### 文件夹自定义图标

- 检测文件夹 `desktop.ini` 中的 `IconResource`、`IconFile` 或 `CLSID=`。
- 带自定义类/图标的文件夹通过 Shell 解析图标，普通文件夹继续使用缓存图标。
- 已验证 `C:\Windows\Offline Web Pages` 在父目录中显示为带蓝色地球的 Offline Web Pages 图标。

## 继承自 0.7.1

- 固定组件池高性能滚动，以及不支持视图的自动传统回退。
- 自适应内容视图、标签页完整路径和窗口上方原生 tooltip。
- MTP/便携设备的完整面包屑、导航树、容量页、详细信息容量列和右键菜单。
- MTP 地址解析、MTP 存储根禁止粘贴、MTP 复制/粘贴和永久删除。
- 回收站可用性检测、Shift+点击删除/Shift+Delete 永久删除。
- Ctrl+双击多开、链接箭头尺寸、任务栏图标裁边、窗口拖动期间暂停后台刷新。

- Release 构建和独立启动验证通过，文件版本为 `0.7.2.0`。
- 已实际截图验证传统菜单复制、文件行右键菜单、粘贴位于刷新下方、示例文件夹自定义图标。
