# 本地测试版：导航、图标与标签页选项（2026-10-19）

本轮不上传 GitHub、不创建 Release。保留上一版测试包。

## 行为

- 文件夹选项「常规」新增启动页：主文件夹、此电脑、快速访问。默认主文件夹；显式传入的打开或定位路径优先于启动页。
- 新标签页可选择打开当前目录或此电脑，默认当前目录；加号与 Ctrl+T 使用同一设置。
- 快速访问的文件夹默认在新标签页打开，可关闭此设置；鼠标与键盘操作均支持。Ctrl/Shift 的显式打开方式优先。
- 快速访问标签页图标缩至原来的 75%；标签页关闭图标放大至上一版的 127%，使用独立的 24×24 居中按钮，避免通用按钮的间距影响位置。
- 快速访问图钉标记也缩至上一版的 75% 并右移，同时为侧边栏的覆盖式滚动条保留空隙。
- 地址栏右侧空白可进入编辑；编辑背景与路径面包屑一致。首次点击全选，第二次及后续普通点击定位末尾，不再跳回开头；Ctrl+L 全选，拖动、Shift 选择及键盘定位仍可用。长路径横向滚动以保持光标可见，鼠标命中及输入法位置同步偏移。光标继承当前主题文字颜色。地址未改动时点 X 立即还原路径显示；修改后点 X 清空，再点击文件区空白等外部区域时立即恢复原路径。
- 多选状态栏显示项目数、所选数量及文件大小；普通模式不计算文件夹。统计模式显示文件和已有文件夹统计结果之和，使用饱和加法，不在渲染中扫描目录。
- 不支持预览的文件显示同一份详细信息及 96 逻辑像素图标；详细信息区域可滚动，大图标加载前使用同尺寸的官方 SVG 占位。
- 保留上一轮版本号、回收站专用列、原生属性页及清空回收站按钮。

## 指定图标来源

两种 Windows 版本使用同一套资源映射，不再由 Windows 11 的 SVG 发现逻辑覆盖下列资源。

| 项目 | 来源 |
|---|---|
| 后退、前进、向上、刷新 | Segoe Fluent Icons：E72B、E72A、E74A、E72C |
| 地址栏电脑、搜索 | Segoe Fluent Icons：E7F4、E721 |
| 主文件夹 | shell32.dll #51380 |
| 桌面、下载、文档、图片、音乐、视频 | imageres.dll #183、184、112、113、108、189 |
| 此电脑、网络、图钉 | imageres.dll #109、25、5100 |

字体不存在时保留系统 Segoe MDL2 同码位兼容回退，再缺失时使用已附许可证的微软 Fluent SVG；不使用 emoji。应用程序自身继续使用原生成图标。更新原生图标缓存版本，防止沿用旧桌面图标。

- 全目标 Clippy 扫描已完成；保留既有的类型复杂度、嵌套条件、可简化表达式等风格建议，没有把全仓库格式重写混进本轮功能修改。

- 发现并修正键盘打开回收站仍调用系统窗口的问题，统一内部导航。
- 使用独立 LOCALAPPDATA 配置和自建临时目录验证，不更改日常设置、不改变默认文件管理器关联、不清空用户回收站。

- 优化版构建已通过。指定的 10 个 DLL 资源图标均在本机成功加载并生成缓存图像。
- 后续修正：清空回收站移入原文件操作工具栏，不再占用独立一行；窄窗口预留按钮宽度，其余操作沿用原有溢出菜单。短路径和长路径点击进入编辑时光标位于末尾、长路径滚动后点击中间定位均已实测。仅检查按钮位置，未执行清空回收站。

- 回归验证：拖选部分路径仍可用；补全列表显示后，点击候选可以进入文件夹，没有被新增的外部点击失焦逻辑打断。
