# Rust Explorer 0.8.11

## 更新内容

- 顶部「…」菜单新增「在此处打开 PowerShell」。在地址栏输入 cmd 并回车可打开命令提示符。两个入口均使用当前文件系统目录，CMD 也支持 UNC 网络共享。右键菜单恢复为 0.8.9 的行为。
- 修复 Rust Explorer 窗口之间涉及 MTP 设备的拖放交接。默认复制，按住 Shift 可移动。已在 Xiaomi 14 验证双向复制，设备内移动仍待确认。应用内拖放交接数据缺失时会拒绝操作，避免退回同步传输。

## 下载和更新

- 已安装 0.8.9 或之前撤回的 0.8.10 的用户可在「文件夹选项」点击「检查更新」，由应用从 GitHub 下载、校验、替换并重启。
- 首次使用可直接运行 Windows x64 便携 EXE，也可完整解压 ZIP 后运行。可用同版本的 SHA256SUMS.txt 核对下载文件。
